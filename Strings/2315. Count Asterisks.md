# ⭐ Count Asterisks

> **Platform:** LeetCode | **Topic:** String | **Technique:** Linear Scan + Toggle State

**Question Link:** [https://leetcode.com/problems/count-asterisks/](https://leetcode.com/problems/count-asterisks/)

---

## 📌 Problem Summary

Given a string `s` containing letters, `'|'`, and `'*'`, count all `'*'` characters that are **outside** pairs of `'|'`. Characters between a pair of `|...|` are ignored.

    s = "l|*e*et|c**o|*de|"
    Outside pipes: "l" + "c**o" + ""  → count ** = 2

---

## 💡 Core Intuition

Track how many `'|'` bars have been seen so far. When `bars` is **even**, we're outside a pair — count any `'*'` seen. When `bars` is **odd**, we're inside a pair — ignore `'*'`.

> 🚦 **Analogy:** `|` acts like a light switch — every `|` toggles you between "inside" and "outside" mode. Only count stars when the light is on (outside = even bars seen).

---

## 🤔 Why `bars % 2 == 0`?

    bars = 0 → outside (no pair opened yet)     → count *
    bars = 1 → inside  (one | seen, pair opened) → ignore *
    bars = 2 → outside (pair closed)             → count *
    bars = 3 → inside  (new pair opened)         → ignore *

    Even bars = outside a pair ✅
    Odd bars  = inside a pair  ❌

---

## 🪜 Algorithm Steps

1. 🏁 Initialize `bars = 0`, `cnt = 0`
2. 🔁 Scan each character:
   - `'|'` → `bars++` (toggle state)
   - `'*'` AND `bars % 2 == 0` → `cnt++` (outside a pair)
3. 📤 Return `cnt`

### Dry Run Example

    s = "p|*ste|ll**arx"

    i=0  'p'  bars=0              cnt=0
    i=1  '|'  bars=1              cnt=0
    i=2  '*'  bars=1 (odd) → skip cnt=0
    i=3  's'  bars=1              cnt=0
    i=4  't'  bars=1              cnt=0
    i=5  'e'  bars=1              cnt=0
    i=6  '|'  bars=2              cnt=0
    i=7  'l'  bars=2              cnt=0
    i=8  'l'  bars=2              cnt=0
    i=9  '*'  bars=2 (even) → ✅  cnt=1
    i=10 '*'  bars=2 (even) → ✅  cnt=2
    i=11 'a'  bars=2              cnt=2
    i=12 'r'  bars=2              cnt=2
    i=13 'x'  bars=2              cnt=2

    Output: 2 ✅

### Pseudocode

    countAsterisks(s):
        bars = 0,  cnt = 0

        for ch in s:
            if ch == '|' → bars++
            if ch == '*' AND bars % 2 == 0 → cnt++

        return cnt

### Full C++ Solution

```cpp
class Solution {
public:
    int countAsterisks(string s) {
        int bars = 0, cnt = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s[i] == '|') bars++;                        // toggle state
            if (s[i] == '*' && bars % 2 == 0) cnt++;        // outside pair
        }
        return cnt;
    }
};
```

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | `bars % 2 == 0` elegantly replaces a boolean toggle — fewer variables |
| 2 | `'|'` is always counted regardless — it's the delimiter, not content |
| 3 | Problem guarantees `'|'` comes in pairs — no need to handle odd total bars |
| 4 | Order matters: check `'|'` **before** `'*'` in case both conditions matter simultaneously (they can't here, but good practice) |

---

## ⚠️ Common Mistakes

- ❌ **Counting `*` when `bars % 2 == 1`** → counting inside pairs instead of outside
- ❌ **Using a boolean toggle** → works too, but `bars % 2` is more concise
- ❌ **Counting `|` as a star** → only `*` is counted, ensure char check is exact

---

## 🔁 Boolean Toggle Alternative

Same logic using an explicit `inside` flag:

    bool inside = false;
    for ch in s:
        if ch == '|' → inside = !inside   // flip
        if ch == '*' AND !inside → cnt++

    Equivalent — just more explicit about the "inside/outside" semantics.
