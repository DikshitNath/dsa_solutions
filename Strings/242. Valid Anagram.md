# 🔤 Valid Anagram

> **Platform:** LeetCode | **Topic:** Hashing / Arrays | **Technique:** Frequency Difference Array

**Question Link:** [https://leetcode.com/problems/valid-anagram/](https://leetcode.com/problems/valid-anagram/)

---

## 📌 Problem Summary

Given two strings `s` and `t`, return `true` if `t` is an anagram of `s` — i.e., both strings contain the **exact same characters with the same frequencies**.

    s = "anagram", t = "nagaram" → true
    s = "rat",     t = "car"     → false

---

## 💡 Core Intuition

Use a single frequency array of size 26. **Increment** for every character in `s`, **decrement** for every character in `t` — simultaneously in one loop. If both strings are anagrams, every character's net count will be **zero**.

> ⚖️ **Analogy:** A balance scale — `s` adds weight on the left, `t` removes weight. If perfectly balanced (all zeros), they're anagrams.

---

## 🤔 Why One Array Instead of Two?

Naive approach: two separate frequency maps, then compare them.

This approach: one array, increment for `s` and decrement for `t` simultaneously → **net difference** tells the whole story. One pass + one check instead of two passes + element-wise comparison.

    freq[c]++ for s,  freq[c]-- for t
    → freq[c] == 0 means equal counts in both ✅

---

## 🪜 Algorithm Steps

1. ⚡ Early exit: if `s.length() != t.length()` → return `false`
2. 🏁 Initialize `mpp[26] = {0}`
3. 🔁 For each index `i`:
   - `mpp[s[i] - 'a']++` → count char in `s`
   - `mpp[t[i] - 'a']--` → uncount char in `t`
4. 🔁 Check all 26 slots — if any `mpp[i] != 0` → return `false`
5. 📤 Return `true`

## 🧩 Code Walkthrough

### Dry Run — Valid Anagram

    s = "eat", t = "tea"

    i=0: s[0]='e'→mpp[4]++,  t[0]='t'→mpp[19]--
    i=1: s[1]='a'→mpp[0]++,  t[1]='e'→mpp[4]--
    i=2: s[2]='t'→mpp[19]++, t[2]='a'→mpp[0]--

    Final mpp (only non-zero shown):
    mpp[0]  = 1-1 = 0  ('a')
    mpp[4]  = 1-1 = 0  ('e')
    mpp[19] = 1-1 = 0  ('t')

    All zeros → return true ✅

### Dry Run — Invalid Anagram

    s = "rat", t = "car"

    i=0: s='r'→mpp[17]++, t='c'→mpp[2]--
    i=1: s='a'→mpp[0]++,  t='a'→mpp[0]--
    i=2: s='t'→mpp[19]++, t='r'→mpp[17]--

    mpp[2]  = -1  ('c') ≠ 0
    mpp[19] = +1  ('t') ≠ 0

    → return false ✅

### Pseudocode

    isAnagram(s, t):
        if len(s) != len(t): return false

        mpp[26] = {0}

        for i in range(len(s)):
            mpp[s[i] - 'a']++
            mpp[t[i] - 'a']--

        for i in range(26):
            if mpp[i] != 0: return false

        return true

### Full C++ Solution

```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.length() != t.length()) return false;  // quick reject

        vector<int> mpp(26, 0);

        for (int i = 0; i < s.length(); i++) {
            mpp[s[i] - 'a']++;   // count s
            mpp[t[i] - 'a']--;   // uncount t
        }

        for (int i = 0; i < 26; i++)
            if (mpp[i] != 0) return false;  // net diff found

        return true;
    }
};
```

## 📊 Complexity Analysis

| Metric | Complexity | Reason |
|--------|-----------|--------|
| ⏱️ **Time** | O(N) | One pass over strings + O(26) = O(N) |
| 🧠 **Space** | O(1) | Fixed 26-element array, independent of input size |

---

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **Single array** for both strings — increment for `s`, decrement for `t` |
| 2 | **Early length check** eliminates impossible cases immediately |
| 3 | **O(1) space** — array size is always 26, regardless of input length |
| 4 | Simultaneous loop is cleaner than two separate frequency-counting loops |

---

## ⚠️ Common Mistakes

- ❌ **Skipping length check** → wastes time processing strings that can't be anagrams
- ❌ **Two separate maps then comparing** → correct but unnecessarily verbose
- ❌ **`mpp[s[i]]` instead of `mpp[s[i]-'a']`** → index out of bounds (ASCII value of `'a'` is 97)
- ❌ **Only checking `mpp[i] < 0`** → missing positive imbalances too; must check `!= 0`

---

## 🆚 Approach Variants

| Approach | Time | Space | Notes |
|----------|------|-------|-------|
| **Frequency diff array** (this) | O(N) | O(1) | Best for lowercase only |
| Two `unordered_map` | O(N) | O(N) | Works for Unicode/any chars |
| Sort both strings | O(N log N) | O(1) | Simple but slower |
| Single `unordered_map` | O(N) | O(N) | More general, handles Unicode |

> 📝 **Follow-up:** If `s` and `t` contain **Unicode characters**, switch to `unordered_map<char, int>` — the fixed-size array only works for lowercase English letters.
