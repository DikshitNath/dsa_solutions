# ⭐ Removing Stars From a String

> **Platform:** LeetCode | **Topic:** Stack / String | **Technique:** String as Stack

**Question Link:** [https://leetcode.com/problems/removing-stars-from-a-string/](https://leetcode.com/problems/removing-stars-from-a-string/)

---

## 📌 Problem Summary

Given a string `s` containing letters and `'*'`, repeatedly remove each `'*'` along with the **closest non-star character to its left**. Return the resulting string.

    Input:  "leet**cod*e"
    Output: "lecoe"

---

## 💡 Core Intuition

Use the result string itself as a **stack**. For each character:
- Regular letter → `push_back` (add to stack)
- `'*'` → `pop_back` (remove the top = closest left character)

> 🧹 **Analogy:** Typing on a keyboard — every `*` is a backspace key that deletes the last character typed.

---

## 🤔 Why Use `string` as a Stack?

`std::string` supports `push_back` and `pop_back` in O(1) — making it a perfect stack that **also directly gives the final answer** without needing to reverse or convert anything at the end.

    stack<char> → needs reconstruction at end
    string res  → IS the answer already ✅

---

## 🪜 Algorithm Steps

1. 🏁 Initialize empty string `res`
2. 🔁 For each character `ch`:
   - `ch == '*'` → `res.pop_back()` (delete last char)
   - Otherwise → `res.push_back(ch)` (add char)
3. 📤 Return `res`

### Pseudocode

    removeStars(s):
        res = ""

        for ch in s:
            if ch == '*':
                res.pop_back()      // backspace — remove last char

### Full C++ Solution

```cpp
class Solution {
public:
    string removeStars(string s) {
        string res = "";

        for (char ch : s) {
            if (ch == '*') res.pop_back();   // remove closest left char
            else           res.push_back(ch); // add char to result
        }

        return res;
    }
};
```

| 🧠 **Space** | O(N) | Result string holds at most N characters |

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **`string` acts as a stack** — `push_back` and `pop_back` are O(1) |
| 2 | No need for a separate `stack<char>` — result string IS the stack |
| 3 | Problem guarantees input is always valid — `pop_back` never called on empty string |
| 4 | This is essentially simulating a **backspace operation** character by character |

---

## ⚠️ Common Mistakes

- ❌ **Using `stack<char>`** and then reversing → extra work; string is cleaner
- ❌ **`pop_back` on empty string** → undefined behavior, but problem guarantees this won't happen
- ❌ **Modifying the original string in-place** → index shifting makes it error-prone

---

## 🆚 This vs Remove Adjacent Duplicates

| Feature | Remove Stars | Remove Adjacent Duplicates |
|---------|-------------|---------------------------|
| Pop condition | `ch == '*'` | `ch == st.top()` |
| Push condition | any non-`*` | any char |
| What gets removed | prev char + star | both matching chars |
| Pattern | Explicit delete operator | Self-cancelling pairs |
