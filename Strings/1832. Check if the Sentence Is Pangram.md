# 🔤 Check if the Sentence Is Pangram

> **Platform:** LeetCode 1832 | **Topic:** Strings / Hashing | **Technique:** Frequency Array with Counter

**Question Link:** https://leetcode.com/problems/check-if-the-sentence-is-pangram/

---

## 📌 Problem Summary

A **pangram** is a sentence containing every letter of the English alphabet at least once. Given a lowercase string `sentence`, return `true` if it is a pangram.

```
"thequickbrownfoxjumpsoverthelazydog" → true  (contains all 26 letters)
"leetcode"                             → false (missing many letters)
```

---

## 💡 Core Intuition

Mark each letter as seen using a frequency array. Count distinct letters as you go — once `cnt == 26`, all letters seen. If the loop ends with `cnt < 26`, it's not a pangram.

---

## 💻 Your Solution

```cpp
class Solution {
public:
    bool checkIfPangram(string sentence) {
        vector<int> arr(26, 0);
        int cnt = 0;

        for (char ch : sentence) {
            if (arr[ch - 'a'] == 0) {   // first time seeing this letter
                arr[ch - 'a']++;
                cnt++;
            }
        }

        return cnt == 26;
    }
};
```

**Your approach is correct and clean.** The `if (arr[...] == 0)` guard ensures `cnt` only increments on the **first occurrence** of each letter — tracking distinct letters, not total frequency.

## 🔁 Three Equivalent Approaches

### Approach 1 — Your Code (Counter + Array)

```cpp
// Tracks distinct count via cnt variable
// Slightly optimized: can add early return if cnt==26
bool checkIfPangram(string sentence) {
    vector<int> arr(26, 0);
    int cnt = 0;
    for (char ch : sentence) {
        if (arr[ch-'a'] == 0) { arr[ch-'a']++; cnt++; }
        if (cnt == 26) return true;   // ← early exit optimization
    }
    return cnt == 26;
}
```

### Approach 2 — Boolean Array (Cleaner)

```cpp
// No counter needed — just check if all 26 are true at end
bool checkIfPangram(string sentence) {
    vector<bool> seen(26, false);
    for (char ch : sentence)
        seen[ch - 'a'] = true;
    for (bool b : seen)
        if (!b) return false;
    return true;
}
```

### Approach 3 — Bitmask (Most Elegant)

```cpp
// Each bit in a 32-bit int represents one letter (26 bits used)
// All 26 letters seen = bits 0-25 all set = 0x3FFFFFF = (1<<26)-1
bool checkIfPangram(string sentence) {
    int mask = 0;
    for (char ch : sentence)
        mask |= (1 << (ch - 'a'));
    return mask == (1 << 26) - 1;   // = 0x3FFFFFF = 67108863
}
```

## 🧩 Dry Run — Bitmask

```
sentence = "abc"

ch='a': mask |= (1<<0) → mask = 0b001
ch='b': mask |= (1<<1) → mask = 0b011
ch='c': mask |= (1<<2) → mask = 0b111

(1<<26)-1 = 0b11111111111111111111111111 (26 ones)
mask = 0b111 ≠ target → return false ✅
```

## 📊 Complexity Analysis

| Approach | Time | Space | Notes |
|---------|------|-------|-------|
| Counter + Array (yours) | O(N) | O(26)=O(1) | Clean, early exit possible |
| Boolean Array | O(N) | O(26)=O(1) | Cleanest to read |
| Bitmask | O(N) | O(1) | Most compact, bit manipulation |

All approaches are O(N) time and O(1) space — the alphabet is fixed at 26.

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **`if (arr[ch-'a'] == 0)`** — counts only distinct letters, not total occurrences |
| 2 | **Early exit** — add `if (cnt == 26) return true` inside loop for long strings |
| 3 | **Bitmask** — single integer tracks all 26 letters; `(1<<26)-1` = all bits set |
| 4 | **`cnt == 26`** vs **`cnt == sentence.size()`** — common confusion; it's always 26 |
| 5 | Problem guarantees only lowercase letters — no bounds check needed |

---

## ⚠️ Common Mistakes

- ❌ **`arr[ch-'a']++` without guard** → cnt never gets incremented → wrong (need to increment cnt separately)
- ❌ **`return sentence.size() >= 26`** → length ≥ 26 doesn't mean all letters present
- ❌ **`cnt == sentence.size()`** → should always be 26, not sentence length

## 🔁 Bitmask Explained

```
26 letters → 26 bits → fits in a single int (32 bits)

Letter 'a' → bit 0  (1 << 0 = 1)
Letter 'b' → bit 1  (1 << 1 = 2)
...
Letter 'z' → bit 25 (1 << 25)

All 26 letters present:
  (1 << 26) - 1 = 0x3FFFFFF
  = 0b00111111111111111111111111

mask |= (1 << (ch-'a'))  → sets the bit for ch
mask == (1<<26)-1        → all 26 bits set = pangram ✅
```
