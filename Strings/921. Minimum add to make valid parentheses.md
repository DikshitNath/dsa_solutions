# 🔧 Minimum Add to Make Parentheses Valid

> **Platform:** LeetCode | **Topic:** Stack / Greedy | **Technique:** Counter-based Greedy

**Question Link:** [https://leetcode.com/problems/minimum-add-to-make-parentheses-valid/](https://leetcode.com/problems/minimum-add-to-make-parentheses-valid/)

---

## 📌 Problem Summary

Given a string `s` of `'('` and `')'`, return the **minimum number of parentheses** you must add to make the string valid.

    "(())"   → 0   (already valid)
    "((("    → 3   (need 3 closing)
    "())("   → 2   (1 unmatched ')' + 1 unmatched '(')
    "()))"   → 3   (1 unmatched '(' wait... = 1 open ')' unmatched)

---

## 💡 Core Intuition

Track two counters:
- `open` → unmatched `(` seen so far (need a `)` to close them)
- `close` → unmatched `)` seen so far (no `(` was available)

> 🪣 **Analogy:** `open` is a bucket of unmatched openers waiting for closers. Every `)` either picks one from the bucket — or if the bucket is empty, it's an orphan counted in `close`.

---

## 🤔 Why No Stack Needed?

A real stack would push `(` and pop on `)`. But here, since all characters are identical within each type, we only need the **count** of unmatched openers — not which specific ones. A counter replaces the stack entirely → O(1) space.

    stack<char> → tracks individual unmatched '('
    int open    → tracks the COUNT of unmatched '(' ✅ simpler

---

## 🪜 Algorithm Steps

1. 🏁 Initialize `open = 0`, `close = 0`
2. 🔁 For each character `ch`:
   - `ch == '('` → `open++` (new unmatched opener)
   - `ch == ')'` AND `open > 0` → `open--` (matched! consume one opener)
   - `ch == ')'` AND `open == 0` → `close++` (orphan closer, no opener left)
3. 📤 Return `open + close`

---

## 🧩 Code Walkthrough

### Dry Run 1 — Mixed

    s = "())"

    ch='(' → open=1, close=0
    ch=')' → open>0 → open=0, close=0
    ch=')' → open=0 → close=1

    return open + close = 0 + 1 = 1 ✅
    (add one '(' at start)

### Dry Run 2 — Multiple Unmatched

    s = "())("

    ch='(' → open=1, close=0
    ch=')' → open>0 → open=0
    ch=')' → open=0 → close=1
    ch='(' → open=1

    return 1 + 1 = 2 ✅
    (1 unmatched ')' + 1 unmatched '(')

### Dry Run 3 — All Openers

    s = "((("

    ch='(' → open=1
    ch='(' → open=2
    ch='(' → open=3

    return 3 + 0 = 3 ✅
    (need 3 closing brackets)

### Pseudocode

    minAddToMakeValid(s):
        open = 0, close = 0

        for ch in s:
            if ch == '(':
                open++                   // unmatched opener
            else if open > 0:
                open--                   // matched with existing opener
            else:
                close++                  // orphan closer

        return open + close              // total insertions needed

### Full C++ Solution

```cpp
class Solution {
public:
    int minAddToMakeValid(string s) {
        int open = 0, close = 0;

        for (char ch : s) {
            if (ch == '(')       open++;    // new unmatched opener
            else if (open > 0)   open--;    // ')' matches an opener
            else                 close++;   // orphan ')' — no opener available
        }

        return open + close;    // unmatched '(' + unmatched ')'
    }
};
```

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | `open` = unmatched `(` → each needs one `)` added |
| 2 | `close` = unmatched `)` → each needs one `(` added |
| 3 | Counter replaces stack → O(1) space since only count matters |
| 4 | `open--` only when `open > 0` — greedy match as early as possible |

---

## ⚠️ Common Mistakes

- ❌ **Not handling `open == 0` before decrementing** → `open` goes negative
- ❌ **Returning only `open` or only `close`** → missing one type of unmatched bracket
- ❌ **Using a stack** → correct but wastes O(N) space unnecessarily for this problem

---

## 🔁 What Each Variable Represents at the End

    open  → '(' brackets that never found a closing ')'  → add ')' for each
    close → ')' brackets that found no opening '('       → add '(' for each
    open + close → minimum total insertions needed

---

## 🆚 Counter vs Stack Approach

| Feature | Counter (this) | Stack-based |
|---------|---------------|-------------|
| Space | O(1) ✅ | O(N) |
| Time | O(N) | O(N) |
| Code simplicity | Simpler ✅ | More verbose |
| Works when chars differ? | ❌ | ✅ |

> 📝 Counter works here because `(` and `)` are the only two characters — no need to track types. For mixed brackets like `{[()]}`, you'd need a real stack.
