# 🗑️ Remove Nth Node From End of List

> **Platform:** LeetCode | **Topic:** Linked List | **Technique:** Two-Pass (Length + Direct Delete)

**Question Link:** [https://leetcode.com/problems/remove-nth-node-from-end-of-list/](https://leetcode.com/problems/remove-nth-node-from-end-of-list/)

---

## 📌 Problem Summary

Given the `head` of a linked list and integer `n`, remove the **nth node from the end** of the list and return the head.

    List: 1 → 2 → 3 → 4 → 5,  n=2
    Output: 1 → 2 → 3 → 5   (4 is the 2nd from end)

---

## 💡 Core Intuition

Find the **length** of the list first. The nth node from the end = `(len - n + 1)`th node from the front. Navigate to the node **before** it and skip it with `prev->next = prev->next->next`.

> ✂️ **Analogy:** Count all people in a queue first. Then walk up to the person just before the one you want to remove, and tell them to hold hands with the person two spots ahead — skipping the target.

---

## 🤔 Why Navigate to `len - n - 1`?

We need to stop at the node **before** the target to perform deletion:

    Target position from front = len - n + 1   (1-indexed)
    Node BEFORE target         = len - n        (1-indexed)
    Loop runs from 1 to len-n-1 steps from head = reaches (len-n)th node ✅

    Example: len=5, n=2
    Target = 5-2+1 = 4th node
    Stop at = 3rd node → loop runs i=1 to i=2 (len-n-1 = 2 steps) ✅

---

## 🤔 Why Special Case `len == n`?

If `len == n`, the **head itself** is the nth from end. We can't go to a node before the head — just return `head->next`.

    List: 1 → 2 → 3, n=3
    len=3, n=3 → remove head → return head->next (2→3) ✅

---

## 🪜 Algorithm Steps

1. 📏 **Pass 1** — count length `len`
2. 🚫 If `len == n` → return `head->next` (remove head)
3. 🔁 **Pass 2** — walk `len-n-1` steps to reach node before target
4. ✂️ Skip target: `temp->next = temp->next->next`
5. 📤 Return `head`

## 🧩 Code Walkthrough

### Dry Run Example

    List: 1 → 2 → 3 → 4 → 5,  n=2

    Pass 1: len = 5

    len != n (5 != 2) → no special case

    Steps to walk: len-n-1 = 5-2-1 = 2
    Start at node 1:
      i=1: temp → node 2
      i=2: temp → node 3

    temp = node 3
    temp->next = node 4 (target)
    temp->next->next = node 5

    temp->next = node 5   → 3 now points to 5, node 4 removed ✅

    Result: 1 → 2 → 3 → 5 ✅

### Index Mapping Visualized

    Positions (1-indexed from front):
    Node:     1    2    3    4    5
    From end: 5    4    3    2    1   ← n=2 means node at position 4

    Stop at position 3 (one before target)
    Loop: i=1 to len-n-1=2 → moves 2 steps from head → reaches node 3 ✅

### Pseudocode

    removeNthFromEnd(head, n):
        // Pass 1: find length
        len = count all nodes

        // Edge case: remove head
        if len == n → return head->next

        // Pass 2: walk to node before target
        temp = head
        walk (len - n - 1) steps

        // Delete target
        temp->next = temp->next->next

        return head

### Full C++ Solution

```cpp
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode* temp = head;
        int len = 0;

        // Pass 1: count length
        while (temp) {
            temp = temp->next;
            len++;
        }

        // Edge case: remove head node
        if (len == n) return head->next;

        // Pass 2: walk to (len-n)th node (1-indexed)
        temp = head;
        for (int i = 1; i <= len-n-1; i++)
            temp = temp->next;

        // Skip the target node
        temp->next = temp->next->next;
        return head;
    }
};
```

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **Navigate to the node BEFORE target** — deletion requires access to `prev->next` |
| 2 | **`len == n` edge case** removes head — can't go "before" head |
| 3 | Loop runs `len-n-1` times — derived from 1-indexed position math |
| 4 | `temp->next->next` is safe here since target is never the last node (that's handled by `len==n` when `n==1`... wait — see note below) |

---

## ⚠️ Common Mistakes

- ❌ **Walking `len-n` steps** → lands on target, not before it → can't delete
- ❌ **Missing `len == n` check** → tries to go before head → null dereference
- ❌ **Off-by-one in loop** (`i < len-n` vs `i <= len-n-1`) → same thing but easy to miscount

---

## 🚀 One-Pass Alternative — Two Pointers

Use a **fast pointer** n steps ahead of slow:

    dummy → head
    fast = dummy,  slow = dummy

    // advance fast n+1 steps
    for i in 0 to n:
        fast = fast->next

    // move both until fast reaches end
    while fast:
        fast = fast->next
        slow = slow->next

    // slow is now just before target
    slow->next = slow->next->next

    return dummy->next

    Time: O(N) | Space: O(1) | Single pass ✅
    Dummy node eliminates the head-removal edge case!
