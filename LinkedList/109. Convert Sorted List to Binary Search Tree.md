# 🌳 Convert Sorted List to Binary Search Tree

> **Platform:** LeetCode 109 | **Topic:** Linked List + Trees | **Technique:** Slow-Fast Pointer (Find Mid) + Divide & Conquer

**Question Link:** https://leetcode.com/problems/convert-sorted-list-to-binary-search-tree/

---

## 📌 Problem Summary

Given the `head` of a **sorted singly linked list**, convert it to a **height-balanced BST** and return the root.

```
List: -10 → -3 → 0 → 5 → 9

One valid BST:
        0
       / \
     -3   9
     /   /
   -10  5

Height-balanced: left and right subtree heights differ by at most 1
```

---

## 💡 Core Intuition

To build a **balanced** BST, always pick the **middle element as root** — this guarantees equal left and right subtree sizes (±1). Recursively do the same for left and right halves.

The challenge: linked lists have **no O(1) random access** — you can't just do `arr[mid]`. Use the **slow-fast pointer technique** to find the middle in O(N).

> 🪓 **Divide & Conquer:** Middle → root. Left half → left subtree. Right half → right subtree. Repeat.

---

## 🔍 Why Middle Element = Balanced Root?

```
List of n elements:
  Left half:  floor((n-1)/2) elements
  Right half: floor(n/2) elements

Heights differ by at most 1 → height-balanced by construction ✅

Example: [-10, -3, 0, 5, 9]  (n=5)
  Middle = index 2 → value 0
  Left:  [-10, -3]  → 2 elements
  Right: [5, 9]     → 2 elements
  Perfectly balanced ✅
```

---

## 🔍 Slow-Fast Pointer — Finding Middle + Previous

```
Goal: find middle node AND the node just before it
      (to cut the list in half)

Initialize: slow=head, fast=head, slow_prev=NULL

Each iteration:
  slow_prev = slow       ← track node before slow
  slow = slow->next      ← slow moves 1 step
  fast = fast->next->next ← fast moves 2 steps

When fast==NULL or fast->next==NULL:
  slow = middle node ✅
  slow_prev = node just before middle ✅
```

---

## 🪜 Algorithm Steps

1. **Base cases:**
   - `!head` → return `NULL`
   - `!head->next` → single node → return `new TreeNode(head->val)`

2. **Find middle** using slow-fast pointers, tracking `slow_prev`

3. **Cut the list:**
   - `slow_prev->next = NULL` → separates left half from middle
   - Left half: `head` to `slow_prev`
   - Right half: `slow->next` onwards

4. **Build tree:**
   - `root = new TreeNode(slow->val)` (middle)
   - `root->left = sortedListToBST(head)` (left half)
   - `root->right = sortedListToBST(slow->next)` (right half)

5. Return `root`

## 🧩 Dry Run

```
List: 1 → 2 → 3 → 4 → 5

Call 1: head=1→2→3→4→5
  slow=1, fast=1, slow_prev=NULL

  Iter 1: slow_prev=1, slow=2, fast=3
  Iter 2: slow_prev=2, slow=3, fast=5
  Iter 3: fast->next = NULL → stop

  slow=3 (middle), slow_prev=2
  Cut: 2->next = NULL
  Left: 1→2, Right: 4→5

  root = TreeNode(3)
  root->left  = sortedListToBST(1→2)
  root->right = sortedListToBST(4→5)

Call 2: head=1→2
  slow=1,fast=1 → iter: slow_prev=1,slow=2,fast=NULL → stop
  slow=2, slow_prev=1
  Cut: 1->next=NULL
  Left: 1, Right: NULL (slow->next=NULL)
  root=TreeNode(2), left=TreeNode(1), right=NULL

Call 3: head=4→5
  slow=4,fast=4 → iter: slow_prev=4,slow=5,fast=NULL → stop
  slow=5, slow_prev=4
  Cut: 4->next=NULL
  Left: 4, Right: NULL
  root=TreeNode(5), left=TreeNode(4), right=NULL

Final BST:
        3
       / \
      2   5
     /   /
    1   4
```

## 💻 Full C++ Solution

```cpp
class Solution {
public:
    TreeNode* sortedListToBST(ListNode* head) {
        if (!head) return NULL;
        if (!head->next) return new TreeNode(head->val);  // single node

        ListNode *slow = head, *fast = head, *slow_prev = NULL;

        // Find middle using slow-fast pointers
        while (fast && fast->next) {
            slow_prev = slow;
            slow = slow->next;
            fast = fast->next->next;
        }

        TreeNode* root = new TreeNode(slow->val);  // middle = root

        slow_prev->next = NULL;                    // cut left half

        root->left  = sortedListToBST(head);        // recurse left
        root->right = sortedListToBST(slow->next);  // recurse right

        return root;
    }
};
```

| 🧠 Space | O(log N) | Recursion stack depth = tree height |

---

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **Middle element → root** guarantees height balance |
| 2 | **`slow_prev` tracks node before mid** — needed to cut the list |
| 3 | **`slow_prev->next = NULL`** — separates left half before recursing |
| 4 | **`root->right = sortedListToBST(slow->next)`** — right half starts AFTER mid |
| 5 | **Two base cases** — `!head` for empty, `!head->next` for single node |

---

## ⚠️ Common Mistakes

- ❌ **`root->right = sortedListToBST(slow)`** → includes mid in right subtree → duplicate root value
- ❌ **Not cutting list (`slow_prev->next = NULL`)** → left recursion includes mid → wrong tree
- ❌ **Starting `fast = head->next`** → off-by-one in mid detection → unbalanced tree
- ❌ **No single-node base case** → `slow_prev` is NULL → crash on `slow_prev->next = NULL`

---

## 🔁 The Single-Node Base Case — Why It's Critical

```
Without base case for single node:
  head = [5] (single node)
  slow=5, fast=5
  Loop: fast->next == NULL → stop immediately (no iteration)
  slow_prev is still NULL!
  slow_prev->next = NULL → NULL POINTER DEREFERENCE 💥

With base case:
  if (!head->next) return new TreeNode(head->val); ✅
  Catches single-node lists before the loop runs
```

---

## 🔁 Why O(N log N) Not O(N)?

```
Level 0: 1 call on N nodes  → traverse N nodes for mid = O(N)
Level 1: 2 calls on N/2     → traverse N/2 each = O(N)
Level 2: 4 calls on N/4     → O(N)
...
Level log N: N calls on 1   → O(N)

Total: O(N) per level × O(log N) levels = O(N log N)
```

Compare to sorted **array** → O(N) since mid is O(1) via index math.

```cpp
// Approach 2 — O(N) time, O(N) space
TreeNode* sortedListToBST(ListNode* head) {
    vector<int> arr;
    while (head) { arr.push_back(head->val); head = head->next; }
    return build(arr, 0, arr.size()-1);
}
TreeNode* build(vector<int>& arr, int l, int r) {
    if (l > r) return NULL;
    int mid = l + (r-l)/2;
    TreeNode* root = new TreeNode(arr[mid]);
    root->left  = build(arr, l, mid-1);
    root->right = build(arr, mid+1, r);
    return root;
}
```
