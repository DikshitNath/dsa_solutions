## 📌 What is DSU?

**Disjoint Set Union (DSU)**, also called **Union-Find**, is a data structure that maintains a collection of **disjoint (non-overlapping) sets** and efficiently answers:
- **Find:** Which group does element `x` belong to?
- **Union:** Merge the groups of elements `x` and `y`

```
Initial: {0} {1} {2} {3} {4}   (everyone in their own group)

union(0,1): {0,1} {2} {3} {4}
union(2,3): {0,1} {2,3} {4}
union(1,3): {0,1,2,3} {4}      (merges entire groups)

find(0) == find(2)? → YES ✅ (same group)
find(0) == find(4)? → NO  ✅ (different groups)
```

---

## 💡 Core Idea — Parent Array

Each element points to a **parent**. The root of the chain (where `par[x] == x`) is the **representative** of the set.

```
Initial (everyone is their own root):
  par = [0, 1, 2, 3, 4]
  
After union(0,1) — par[0]=1:
  par = [1, 1, 2, 3, 4]
  Tree: 0→1  (1 is root)

After union(1,2) — par[1]=2:
  par = [1, 2, 2, 3, 4]
  Tree: 0→1→2  (2 is root)
```

`find(x)` walks up the chain until it hits the root.

## 🔵 Your Code — Basic DSU (No Optimizations)

```cpp
int find(int par[], int x) {
    if (x == par[x]) return x;    // x is its own root
    return find(par, par[x]);      // recurse up the chain
}

void unionSet(int par[], int x, int z) {
    int x_par = find(par, x);
    int z_par = find(par, z);
    if (z_par != x_par) par[x_par] = z_par;  // attach x's root to z's root
}
```

### 📊 Complexity (Basic)

| Operation | Time | Worst Case |
|-----------|------|-----------|
| `find` | O(N) | Linear chain (skewed tree) |
| `union` | O(N) | Calls find twice |

**Problem:** Without optimizations, chains can grow to O(N) depth → O(N) per operation.

---

## 🚨 Two Critical Optimizations

### Optimization 1 — Path Compression

After `find(x)` walks up to the root, **flatten the tree** by pointing every node directly to the root.

```cpp
int find(int par[], int x) {
    if (x == par[x]) return x;
    return par[x] = find(par, par[x]);  // path compression ✅
}
```

```
Before path compression (find(0)):
  0 → 1 → 2 → 3 (root)

After path compression:
  0 → 3
  1 → 3          (all point directly to root)
  2 → 3
```

Next call to `find(0)` → O(1) directly!

---

### Optimization 2 — Union by Rank

Always attach the **smaller tree under the larger tree**. Keeps trees shallow.

```cpp
void unionSet(int par[], int rank[], int x, int z) {
    int xr = find(par, x);
    int zr = find(par, z);

    if (xr == zr) return;   // already in same set

    if (rank[xr] < rank[zr])      par[xr] = zr;
    else if (rank[xr] > rank[zr]) par[zr] = xr;
    else {
        par[zr] = xr;             // tie → attach z under x
        rank[xr]++;               // increment rank of new root
    }
}
```

## 💻 Full Optimized DSU (Path Compression + Union by Rank)

```cpp
class DSU {
    vector<int> par, rank_;

public:
    DSU(int n) : par(n), rank_(n, 0) {
        iota(par.begin(), par.end(), 0);  // par[i] = i
    }

    int find(int x) {
        if (x != par[x])
            par[x] = find(par[x]);   // path compression
        return par[x];
    }

    void unite(int x, int z) {
        int xr = find(x), zr = find(z);
        if (xr == zr) return;

        if (rank_[xr] < rank_[zr])      par[xr] = zr;
        else if (rank_[xr] > rank_[zr]) par[zr] = xr;
        else { par[zr] = xr; rank_[xr]++; }
    }

    bool connected(int x, int z) {
        return find(x) == find(z);
    }
};
```

### 📊 Complexity (Optimized)

| Operation | Time |
|-----------|------|
| `find` | O(α(N)) ≈ O(1) |
| `union` | O(α(N)) ≈ O(1) |

> 📝 **α (Inverse Ackermann function)** — grows so slowly that for all practical purposes α(N) ≤ 5 for any N you'll encounter. Effectively constant time.

```
n=4, Initial: par=[0,1,2,3]

unionSet(par, 0, 1):
  find(0) = 0 (par[0]==0)
  find(1) = 1 (par[1]==1)
  0 ≠ 1 → par[0] = 1
  par=[1,1,2,3]

unionSet(par, 2, 3):
  find(2) = 2, find(3) = 3
  par[2] = 3
  par=[1,1,3,3]

unionSet(par, 0, 2):
  find(0): par[0]=1, par[1]=1 → root=1
  find(2): par[2]=3, par[3]=3 → root=3
  1 ≠ 3 → par[1] = 3
  par=[1,3,3,3]

find(0) = root of 0: 0→1→3 = 3
find(2) = root of 2: 2→3   = 3
find(0) == find(2) → SAME SET ✅
```

## 🧩 Dry Run — Path Compression Effect

```
Before: par=[1,3,3,3]  (0→1→3 chain)

find(0) with path compression:
  find(0): par[0]=1 → find(1)
    find(1): par[1]=3 → find(3)
      find(3): par[3]=3 → return 3
    par[1] = 3 ← compressed!
  par[0] = 3 ← compressed!
  return 3

After: par=[3,3,3,3]  (everything points directly to root 3 ✅)
Next find(0) → O(1) single lookup
```

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **`par[x] == x` → x is root** — base case for `find` |
| 2 | **Path compression** — `par[x] = find(par[x])` flattens tree on the way back |
| 3 | **Union by rank** — attach smaller tree under larger to prevent skewing |
| 4 | **Together → O(α(N))** — near O(1), best possible for this problem |
| 5 | **`find(x) == find(y)` → connected** — the key check in most graph problems |

---

## ⚠️ Common Mistakes

- ❌ **No path compression** → O(N) per operation on linear chains
- ❌ **`par[x] = z` instead of `par[xr] = zr`** → attaching nodes instead of roots → corrupts structure
- ❌ **Not initializing `par[i] = i`** → every element must be its own parent initially
- ❌ **Skipping `xr == zr` check in union** → self-loop or unnecessary work

## 🔁 DSU in Graph Problems

```
Common use cases:

1. Detect cycle in undirected graph:
   For each edge (u,v):
     if find(u) == find(v) → CYCLE ✅
     else union(u, v)

2. Count connected components:
   Initial components = N
   For each union that merges different sets: components--

3. Kruskal's MST:
   Sort edges by weight
   Add edge if find(u) != find(v) → union(u,v)

4. Dynamic connectivity:
   Answer "are u and v connected?" after each union
```
