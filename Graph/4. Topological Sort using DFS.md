# 🗂️ Topological Sort (DFS)

> **Platform:** GFG / LeetCode | **Topic:** Graphs | **Technique:** DFS + Post-order Stack Push

**GFG Link:** https://www.geeksforgeeks.org/topological-sorting/

---

## 📌 Problem Summary

Given a **Directed Acyclic Graph (DAG)** with `V` vertices and edges, return a **topological ordering** — a linear arrangement of nodes such that for every directed edge `u → v`, node `u` appears **before** node `v`.

```
Edges: 5→0, 5→2, 4→0, 4→1, 2→3, 3→1

One valid output: [5, 4, 2, 3, 1, 0]
Another valid:    [4, 5, 2, 3, 1, 0]

(Multiple valid answers exist)
```

> 📝 Topological sort is only defined for **DAGs** — graphs with no cycles.

---

## 💡 Core Intuition

Run DFS. When you're done exploring **all neighbors** of a node (post-order), push it onto a stack. Since a node is pushed only after all nodes it depends on are pushed, popping the stack gives the correct order — dependencies come first.

> 📦 **Analogy:** Getting dressed. You can't put on shoes before socks, can't wear a shirt before an undershirt. DFS explores the deepest dependency first, then pushes on the way back — so the stack pops in the correct "put on" order.

---

## 🤔 Why Push AFTER Recursion (Post-order)?

```
Edge: u → v  means "u must come before v"

DFS(u):
  DFS(v)          ← visit v first (go deeper)
  st.push(u)      ← push u AFTER v is fully done

Stack (bottom→top): [..., v, ..., u]
Pop order: u comes out before v ✅
```

If you pushed **before** recursion (pre-order):
```
DFS(u):
  st.push(u)      ← push u first
  DFS(v)          ← then visit v

Pop order: v comes out before u ❌ (wrong — u should precede v)
```

Post-order push = "I'm done with everything I depend on, now place me."

---

## 🤔 Why a Stack and Not Direct `ans` Push?

Post-order DFS naturally produces **reverse topological order**. The deepest node gets pushed first — but it should appear last in the output.

```
Stack push order (DFS post-order): last node → ... → first node
Stack pop order:                   first node → ... → last node ✅

Alternative: push_back to vector, then reverse() at end — same result.
```

---

## 🪜 Algorithm Steps

1. 🏗️ Build adjacency list from `edges`
2. 🏁 Initialize `vis[V] = false`, empty `stack<int> st`
3. 🔁 For each unvisited node `i`, run `dfs(i)`
4. **Inside DFS:**
   - Mark `vis[u] = true`
   - For each neighbor `v`: if `!vis[v]`, recurse
   - **After all neighbors done:** `st.push(u)` ← post-order
5. 🔁 Pop stack into `ans` vector
6. 📤 Return `ans`

## 🧩 Dry Run

```
V=6, Edges: 5→0, 5→2, 4→0, 4→1, 2→3, 3→1

Adjacency list:
  5 → [0, 2]
  4 → [0, 1]
  2 → [3]
  3 → [1]
  0 → []
  1 → []

DFS from 0 (i=0):
  vis[0]=T
  no neighbors → st.push(0)     stack: [0]

DFS from 1 (i=1):
  vis[1]=T
  no neighbors → st.push(1)     stack: [0,1]

DFS from 2 (i=2):
  vis[2]=T
  → DFS(3): vis[3]=T
    → DFS(1): vis[1]=T already → skip
    → st.push(3)                 stack: [0,1,3]
  → st.push(2)                   stack: [0,1,3,2]

DFS from 3: vis[3]=T → skip
DFS from 4 (i=4):
  vis[4]=T
  → DFS(0): vis[0]=T → skip
  → DFS(1): vis[1]=T → skip
  → st.push(4)                   stack: [0,1,3,2,4]

DFS from 5 (i=5):
  vis[5]=T
  → DFS(0): vis[0]=T → skip
  → DFS(2): vis[2]=T → skip
  → st.push(5)                   stack: [0,1,3,2,4,5]

Pop stack → ans = [5, 4, 2, 3, 1, 0] ✅
```

## 💻 Full C++ Solution

```cpp
class Solution {
public:
    vector<int> topoSort(int V, vector<vector<int>>& edges) {
        vector<vector<int>> adj(V);

        for (auto& e : edges) {
            adj[e[0]].push_back(e[1]);    // directed: u → v
        }

        vector<bool> vis(V, false);
        stack<int> st;
        vector<int> ans;

        for (int i = 0; i < V; i++)
            if (!vis[i])
                dfs(adj, i, vis, st);

        while (!st.empty()) {
            ans.push_back(st.top());
            st.pop();
        }

        return ans;
    }

    void dfs(vector<vector<int>>& adj, int u,
             vector<bool>& vis, stack<int>& st) {
        vis[u] = true;

        for (int v : adj[u])
            if (!vis[v])
                dfs(adj, v, vis, st);

        st.push(u);    // post-order: push AFTER all neighbors done
    }
};
```

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **Push after recursion** (post-order) — node pushed only after all dependencies pushed |
| 2 | **Stack reverses** DFS post-order → correct topological order on pop |
| 3 | **Outer loop** handles disconnected components — all nodes visited |
| 4 | Only works on **DAGs** — cycles make topological sort undefined |
| 5 | Multiple valid outputs exist — any order where `u` precedes `v` for all `u→v` is correct |

---

## ⚠️ Common Mistakes

- ❌ **`st.push(u)` before recursion** → pre-order push → wrong order
- ❌ **No outer for loop** → disconnected nodes never visited
- ❌ **Undirected graph edges** → adding both `adj[u]→v` and `adj[v]→u` creates false cycles
- ❌ **Running on cyclic graph** → result is meaningless (use cycle detection first)
- ❌ **Reversing `ans` instead of using stack** → both work but easy to forget the reverse step

---

## 🔁 Why This Works — The Invariant

```
When dfs(u) finishes and pushes u onto the stack:
  ALL nodes reachable from u have ALREADY been pushed.

So on the stack (bottom → top):
  deepest dependency → ... → u

On pop (top → bottom):
  u → ... → deepest dependency

= u appears BEFORE everything it points to ✅
= valid topological order ✅
```

## 🆚 DFS Topo Sort vs Kahn's Algorithm (BFS)

| Feature | DFS + Stack (this) | Kahn's Algorithm (BFS) |
|---------|-------------------|------------------------|
| Approach | Post-order DFS push | Process zero in-degree nodes first |
| Cycle detection | ❌ Needs separate check | ✅ Built-in (processed count < V) |
| Output | Valid topo order | Valid topo order |
| Extra data | Stack | In-degree array + queue |
| Intuition | Dependencies finish before you | Remove nodes with no pending dependencies |
| Use when | Simple topo order needed | Topo order + cycle detection needed |

## 🔁 Kahn's Algorithm Sketch (BFS Topo Sort)

```cpp
// 1. Compute in-degree for all nodes
vector<int> inDeg(V, 0);
for (auto& e : edges) inDeg[e[1]]++;

// 2. Push all zero in-degree nodes to queue
queue<int> q;
for (int i = 0; i < V; i++)
    if (inDeg[i] == 0) q.push(i);

// 3. BFS
vector<int> ans;
while (!q.empty()) {
    int u = q.front(); q.pop();
    ans.push_back(u);
    for (int v : adj[u])
        if (--inDeg[v] == 0) q.push(v);
}

// 4. Cycle check
if (ans.size() != V) // cycle exists!
```
