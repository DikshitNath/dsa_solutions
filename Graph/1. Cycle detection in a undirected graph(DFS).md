# 🔄 Detect Cycle in an Undirected Graph

> **Platform:** GeeksForGeeks | **Topic:** Graph | **Technique:** DFS

**Question Link:** https://www.geeksforgeeks.org/problems/detect-cycle-in-an-undirected-graph/1

---

## 📌 Problem Summary

Given an undirected graph with `V` vertices and a list of edges, determine whether the graph contains **any cycle**.

---

## 💡 Core Intuition

In DFS traversal of an undirected graph, if you visit a neighbor that is **already visited** and is **not your direct parent**, you've found a **back edge** — which means there's a cycle.

> 🥾 **Analogy:** Think of it like walking a trail. If you reach a place you've already been, but didn't just come from there — you've walked in a loop.

---

## 🤔 Why Track the Parent?

In an undirected graph, every edge `u — v` appears in **both** directions.

So when you're at `u` and came from `v`:
- Node `v` is already visited ✅
- But that's **not** a cycle — it's just the edge you came from ❌

The `parent` check skips this case to **avoid false positives**.

---

## 🪜 Algorithm Steps

1. 🏗️ Build an **adjacency list** from the edge list
2. 🔁 Iterate over all vertices to handle **disconnected components**
3. 🚀 For each unvisited vertex, run DFS with `parent = -1`
4. 🔍 Inside DFS, for each neighbor `v`:
   - `v == parent` → ⏭️ skip
   - `v` is already visited → 🚨 **cycle found!** return `true`
   - Otherwise → recurse deeper with `u` as new parent

## 🧩 Code Walkthrough

### Pseudocode

```cpp
bool isCycleDFS(adj, u, vis, parent):
    vis[u] = true
    for v in adj[u]:
        if v == parent → skip
        if vis[v]      → return true   // Back edge = cycle!
        if isCycleDFS(adj, v, vis, u)  // Recurse deeper
            return true
    return false
```

```cpp
bool isCycle(V, edges):
    Build adj list from edges
    for each vertex i:
        if not visited:
            if isCycleDFS(adj, i, vis, -1) → return true
    return false
```


### Full C++ Solution

```cpp
class Solution {
  public:
    bool isCycleDFS(vector<vector<int>>& adj, int u,
                    vector<bool>& vis, int parent) {
        vis[u] = true;
        for (int v : adj[u]) {
            if (v == parent) continue;          // skip parent edge
            if (vis[v]) return true;            // back edge = cycle!
            if (isCycleDFS(adj, v, vis, u))     // recurse
                return true;
        }
        return false;
    }

    bool isCycle(int V, vector<vector<int>>& edges) {
        vector<vector<int>> adj(V);
        for (auto& e : edges) {
            adj[e].push_back(e);
            adj[e].push_back(e);
        }

        vector<bool> vis(V, false);
        for (int i = 0; i < V; i++) {
            if (!vis[i] && isCycleDFS(adj, i, vis, -1))
                return true;
        }
        return false;
    }
};
```

## 📊 Complexity Analysis

| Metric | Complexity | Reason |
|--------|-----------|--------|
| ⏱️ **Time** | `O(V + E)` | Standard DFS visits every node and edge once |
| 🧠 **Space** | `O(V + E)` | Adj list + visited array + recursion stack |

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | `parent` tracking is **critical** — without it, every undirected edge looks like a cycle |
| 2 | The outer `for` loop is essential for **disconnected graphs** |
| 3 | This only works for **undirected** graphs |
| 4 | BFS version works too — same parent-tracking logic applies |

---

## ⚠️ Common Mistakes

- ❌ **Skipping the outer loop** → misses disconnected components
- ❌ **Not passing parent** → every edge triggers a false cycle
- ❌ **Using this for directed graphs** → directed needs `inStack[]`, not just `vis[]`
