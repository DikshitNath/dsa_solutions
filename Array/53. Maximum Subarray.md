# 📈 Maximum Subarray (Kadane's Algorithm)

> **Platform:** LeetCode | **Topic:** Array / DP | **Technique:** Kadane's Algorithm

**Question Link:** [https://leetcode.com/problems/maximum-subarray/](https://leetcode.com/problems/maximum-subarray/)

---

## 📌 Problem Summary

Given an integer array `nums`, find the **contiguous subarray** with the largest sum and return that sum.

    Input:  [-2, 1, -3, 4, -1, 2, 1, -5, 4]
    Output: 6   (subarray: [4, -1, 2, 1])

---

## 💡 Core Intuition

Maintain a **running sum**. If the running sum ever goes negative, it can only hurt any future subarray — so **reset it to 0** and start fresh. At every step, track the maximum sum seen so far.

> 🚶 **Analogy:** You're walking and collecting coins (positive) or paying tolls (negative). If your total balance goes negative, it's better to just drop everything and start fresh from the next step.

---

## 🐛 Bug in Original Code

```cpp
// ❌ BUG
maxSum = max(maxSum, sum + x);   // x is added TWICE — once in sum+=x, once here
```

    After sum += x, `sum` already includes x.
    Using sum+x counts x a second time → wrong answer.

```cpp
// ✅ FIX
maxSum = max(maxSum, sum);       // sum already has x included
```

---

## 🤔 Why Reset Sum to 0 (Not to Current Element)?

If `sum < 0`, any subarray continuing from here starts with a handicap. Resetting to `0` means "start a fresh subarray from the next element." We don't reset to the element itself — we add it after resetting:

    sum = 0
    sum += x   →  sum = x   (fresh start from x)

---

## 🪜 Algorithm Steps

1. 🏁 Initialize `sum = 0`, `maxSum = INT_MIN`
2. 🔁 For each element `x`:
   - If `sum < 0` → reset `sum = 0` (drop the losing streak)
   - Add `x` to `sum`
   - Update `maxSum = max(maxSum, sum)`
3. 📤 Return `maxSum`

### Full C++ Solution (Fixed)

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int sum = 0, maxSum = INT_MIN;

        for (int x : nums) {
            if (sum < 0) sum = 0;       // reset if sum is a liability
            sum += x;
            maxSum = max(maxSum, sum);  // ✅ fixed: was sum+x (double-counted x)
        }
        return maxSum;
    }
};
```

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **Negative running sum = dead weight** — always reset to 0 and start fresh |
| 2 | `maxSum = INT_MIN` handles **all-negative arrays** correctly (e.g. `[-3,-1,-2]` → `-1`) |
| 3 | `maxSum` is updated **after** adding `x` — captures single-element subarrays too |
| 4 | This is essentially a **greedy / sliding window** approach disguised as DP |

---

## ⚠️ Common Mistakes

- ❌ **`maxSum = max(maxSum, sum + x)`** → double-counts `x` (bug in original code)
- ❌ **`maxSum = 0` initialization** → fails for all-negative arrays (returns 0 instead of least negative)
- ❌ **Resetting sum to `x` instead of `0`** → unnecessary, `sum=0; sum+=x` achieves the same cleanly
- ❌ **Not updating `maxSum` every iteration** → might miss the peak mid-array

---

## 🧠 Kadane's as DP

Kadane's algorithm is a space-optimized form of this DP recurrence:

    dp[i] = max subarray sum ending at index i
    dp[i] = max(nums[i], dp[i-1] + nums[i])

    → If dp[i-1] < 0, dp[i] = nums[i]   (start fresh)
    → If dp[i-1] ≥ 0, dp[i] = dp[i-1] + nums[i]   (extend)

    answer = max(dp[0], dp[1], ..., dp[n-1])

Since we only need the previous value, we compress to O(1) space.
