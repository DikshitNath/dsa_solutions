# 🔺 Pascal's Triangle

> **Platform:** LeetCode | **Topic:** Array | **Technique:** Row-by-Row DP Construction

**Question Link:** [https://leetcode.com/problems/pascals-triangle/](https://leetcode.com/problems/pascals-triangle/)

---

## 📌 Problem Summary

Given an integer `numRows`, return the first `numRows` rows of **Pascal's Triangle**, where each element is the sum of the two elements directly above it.

---

## 💡 Core Intuition

Each row starts and ends with `1`. Every interior element at position `j` in row `i` is the sum of two elements from the previous row: `ans[i-1][j]` and `ans[i-1][j-1]`.

    Row 0:      1
    Row 1:     1 1
    Row 2:    1 2 1
    Row 3:   1 3 3 1
    Row 4:  1 4 6 4 1

> 🏔️ **Analogy:** Think of each number as water collecting from the two cells above it. The edges always get exactly 1 drop — the rest accumulates from both parents.

---

## 🤔 Why Initialize Each Row With All 1s?

Each row `i` has `i+1` elements. Filling the entire row with `1` upfront handles:
- **First element** (`j=0`) → already `1` ✅
- **Last element** (`j=i`) → already `1` ✅
- **Interior elements** → overwritten in the inner loop

This avoids any special-case handling for the edges.

---

## 🪜 Algorithm Steps

1. 🏗️ Create `ans` with `numRows` empty rows
2. 🔁 For each row `i`:
   - Initialize `ans[i]` as a vector of size `i+1`, filled with `1`
   - For each interior position `j` from `1` to `i-1`:
     - Set `ans[i][j] = ans[i-1][j] + ans[i-1][j-1]`
3. 📤 Return `ans`

---

## 🧩 Code Walkthrough

### Why Inner Loop is `j = 1` to `j < i`?

    Row i has indices: 0, 1, 2, ..., i
    - j=0  → edge, stays 1 (skip)
    - j=i  → edge, stays 1 (skip)
    - j=1 to j=i-1 → interior, needs computation

    So loop runs from j=1 to j<i — exactly the interior positions.

### Dry Run (numRows = 5)

    i=0: ans[0] = [1]                          (size 1, no interior)
    i=1: ans[1] = [1, 1]                        (size 2, no interior)
    i=2: ans[2] = [1, 1, 1] → j=1: 1+1=2 → [1, 2, 1]
    i=3: ans[3] = [1, 1, 1, 1]
         j=1: ans[2][1]+ans[2][0] = 2+1 = 3
         j=2: ans[2][2]+ans[2][1] = 1+2 = 3
         → [1, 3, 3, 1]
    i=4: ans[4] = [1, 1, 1, 1, 1]
         j=1: 3+1=4,  j=2: 3+3=6,  j=3: 1+3=4
         → [1, 4, 6, 4, 1]

    Output: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]] ✅

### Pseudocode

    generate(numRows):
        ans = []

        for i from 0 to numRows-1:
            ans[i] = array of size (i+1) filled with 1

            for j from 1 to i-1:          // interior only
                ans[i][j] = ans[i-1][j] + ans[i-1][j-1]

        return ans

### Full C++ Solution

```cpp
class Solution {
public:
    vector<vector<int>> generate(int numRows) {
        vector<vector<int>> ans(numRows);

        for (int i = 0; i < numRows; i++) {
            ans[i] = vector<int>(i+1, 1);      // fill row with 1s

            for (int j = 1; j < i; j++) {       // fill interior elements
                ans[i][j] = ans[i-1][j] + ans[i-1][j-1];
            }
        }
        return ans;
    }
};
```

## 📊 Complexity Analysis

| Metric | Complexity | Reason |
|--------|-----------|--------|
| ⏱️ **Time** | O(N²) | Total elements across all rows = 1+2+...+N = N(N+1)/2 |
| 🧠 **Space** | O(N²) | Storing all rows in the output triangle |

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | Pre-filling with `1` elegantly handles both edge elements without extra conditions |
| 2 | Inner loop runs from `j=1` to `j<i` — **strictly interior** positions only |
| 3 | Each cell depends only on the **previous row** — classic 2D DP pattern |
| 4 | Row `i` always has exactly `i+1` elements |

---

## ⚠️ Common Mistakes

- ❌ **Inner loop `j=0` to `j<=i`** → overwrites edge `1`s with wrong values
- ❌ **Not initializing row with `1`** → edges remain unset or zero
- ❌ **Accessing `ans[i-1]` when `i=0`** → out of bounds (loop handles this since `j=1 to j<0` never runs)
