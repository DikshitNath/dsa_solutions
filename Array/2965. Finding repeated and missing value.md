# 🔍 Find Missing and Repeated Values

> **Platform:** LeetCode | **Topic:** Array / Matrix | **Technique:** Frequency Count

**Question Link:** [https://leetcode.com/problems/find-missing-and-repeated-values/](https://leetcode.com/problems/find-missing-and-repeated-values/)

---

## 📌 Problem Summary

Given an `n x n` grid containing values from `1` to `n²`, exactly **one value appears twice** (repeated) and exactly **one value is missing**. Return `[repeated, missing]`.

---

## 💡 Core Intuition

Flatten the grid mentally into a 1D array of `n²` elements. Build a **frequency array** of size `n²+1`. Any value with `freq == 2` is the repeated number, and any value with `freq == 0` is the missing number.

> 🧮 **Analogy:** Roll call for numbers 1 to n². Anyone who answers twice is the duplicate. Anyone who never answers is the missing one.

---

## 🪜 Algorithm Steps

1. 🏗️ Create `freq[]` of size `n²+1`, initialized to `0`
2. 🔁 Traverse the entire grid, incrementing `freq[grid[i][j]]`
3. 🔍 Scan `freq[1]` to `freq[n²]`:
   - `freq[i] == 2` → repeated number `a`
   - `freq[i] == 0` → missing number `b`
4. 📤 Return `{a, b}`

---

## 🧩 Code Walkthrough

### Dry Run Example

    grid = [[1, 3],
            [2, 2]]

    n=2, total=4
    freq after traversal: [0, 1, 2, 1, 0]
                               ↑  ↑  ↑  ↑
                               1  2  3  4

    freq[1]=1 → normal
    freq[2]=2 → repeated → a=2
    freq[3]=1 → normal
    freq[4]=0 → missing  → b=4

    Output: [2, 4] ✅

### Pseudocode

    findMissingAndRepeatedValues(grid):
        total = n * n
        freq[1..total] = all zeros

        for each cell in grid:
            freq[cell]++

        a = -1, b = -1
        for i from 1 to total:
            if freq[i] == 2 → a = i   // repeated
            if freq[i] == 0 → b = i   // missing

        return [a, b]

### Full C++ Solution

```cpp
class Solution {
public:
    vector<int> findMissingAndRepeatedValues(vector<vector<int>>& grid) {
        int n = grid.size();
        int total = n * n;

        vector<int> freq(total+1, 0);   // 1-indexed frequency array

        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                freq[grid[i][j]]++;

        int a = -1, b = -1;
        for (int i = 1; i <= total; i++) {
            if (freq[i] == 2) a = i;    // repeated value
            if (freq[i] == 0) b = i;    // missing value
        }

        return {a, b};
    }
};
```

## 📊 Complexity Analysis

| Metric | Complexity | Reason |
|--------|-----------|--------|
| ⏱️ **Time** | O(N²) | Grid traversal + freq scan both O(N²) |
| 🧠 **Space** | O(N²) | Frequency array of size N²+1 |

---

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | `freq` is **1-indexed** — size `total+1` to use indices 1 to n² directly |
| 2 | Exactly one `freq[i]==2` and one `freq[i]==0` are guaranteed by the problem |
| 3 | Both `a` and `b` are found in a **single pass** over the freq array |
| 4 | Grid structure is irrelevant — treat it as a flat array of n² values |

---

## ⚠️ Common Mistakes

- ❌ **`freq` of size `total`** instead of `total+1` → index `total` (= n²) goes out of bounds
- ❌ **0-indexed freq** → off by one when mapping values to indices
- ❌ **Returning `{b, a}`** → problem asks for `[repeated, missing]` order specifically

---

## 🚀 O(1) Space Alternative (Math)

Using sum and sum of squares to find the two unknowns:

    Let repeated = a,  missing = b

    S  = sum of grid     − n²(n²+1)/2       → gives (a - b)
    S2 = sum of squares  − n²(n²+1)(2n²+1)/6 → gives (a² - b²) = (a+b)(a-b)

    (a + b) = S2 / S
    a = ((a+b) + (a-b)) / 2
    b = ((a+b) - (a-b)) / 2

    Time: O(N²) | Space: O(1) ✅
