# 🪣 Container With Most Water

> **Platform:** LeetCode | **Topic:** Array | **Technique:** Two Pointers

**Question Link:** [https://leetcode.com/problems/container-with-most-water/](https://leetcode.com/problems/container-with-most-water/)

---

## 📌 Problem Summary

Given an array `height` where each element represents a vertical line at that index, find two lines that together with the x-axis form a container that holds the **maximum amount of water**.

    water = min(height[i], height[j]) * (j - i)

---

## 💡 Core Intuition

Start with the **widest possible container** (i=0, j=n-1). The width shrinks as pointers move inward, so to compensate, we must try to find a **taller wall**. Always move the pointer pointing to the **shorter wall** inward — keeping the taller wall is our only hope for more water.

> 🧱 **Analogy:** You have two walls. Water is limited by the shorter one. Moving the taller wall inward can only make things worse (shorter width, same or lower height). So always move the shorter wall, hoping to find something taller.

---

## 🤔 Why Move the Shorter Wall?

Suppose `height[i] < height[j]`:
- Moving `j` inward → width decreases, height still capped by `height[i]` → water can only **decrease or stay same** ❌
- Moving `i` inward → width decreases BUT `height[i]` might increase → water **might increase** ✅

So moving the shorter pointer is the **only rational greedy choice**.

---

## 🪜 Algorithm Steps

1. 🏁 Set `i = 0`, `j = n-1` (widest container)
2. 🔁 While `i < j`:
   - 💧 Compute `water = min(height[i], height[j]) * (j - i)`
   - 📈 Update `maxWater = max(maxWater, water)`
   - ↔️ Move the **shorter** pointer inward:
     - `height[i] < height[j]` → `i++`
     - Otherwise → `j--`
3. 📤 Return `maxWater`

### Pseudocode

    maxArea(height):
        i = 0,  j = n-1
        maxWater = 0

        while i < j:
            water = min(height[i], height[j]) * (j - i)
            maxWater = max(maxWater, water)

            if height[i] < height[j]: i++   // move shorter wall
            else:                     j--

        return maxWater

### Full C++ Solution

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int n = height.size();
        int i = 0, j = n-1;
        int maxWater = 0;

        while (i < j) {
            int water = min(height[i], height[j]) * (j - i);  // area formula
            maxWater = max(maxWater, water);

            if (height[i] < height[j]) i++;     // move shorter pointer
            else j--;
        }
        return maxWater;
    }
};
```

## 📊 Complexity Analysis

| Metric | Complexity | Reason |
|--------|-----------|--------|
| ⏱️ **Time** | O(N) | Each pointer moves inward at most N times total |
| 🧠 **Space** | O(1) | Only a few variables, no extra storage |

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | Always start with **widest container** — max possible width |
| 2 | Move the **shorter wall** — only change that can possibly increase water |
| 3 | Water formula: `min(h[i], h[j]) * (j - i)` — bottlenecked by shorter wall |
| 4 | Two pointer converges in O(N) — no need for O(N²) brute force |

---

## ⚠️ Common Mistakes

- ❌ **Moving the taller pointer** → guaranteed to reduce or maintain water, never increase
- ❌ **Using `height[i] + height[j]`** instead of `min(...)` → water can't rise above shorter wall
- ❌ **Using `j - i + 1`** for width → width is the gap between lines, not inclusive count

---

## 🆚 This vs Trapping Rain Water

| Feature | Container With Most Water | Trapping Rain Water |
|---------|--------------------------|---------------------|
| Goal | Max area between **2 lines** | Total water across **all bars** |
| Approach | Two pointers | Precomputed L/R max arrays |
| Water formula | `min(h[i],h[j]) * (j-i)` | `min(lMax,rMax) - h[i]` per bar |
| Complexity | O(N) time, O(1) space | O(N) time, O(N) space |
