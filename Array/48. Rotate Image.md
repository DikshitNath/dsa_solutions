# 🔄 Rotate Image

> **Platform:** LeetCode | **Topic:** Matrix | **Technique:** Transpose + Reverse

**Question Link:** [https://leetcode.com/problems/rotate-image/](https://leetcode.com/problems/rotate-image/)

---

## 📌 Problem Summary

Given an `n x n` 2D matrix, rotate it **90 degrees clockwise** — **in-place**, without using extra space.

---

## 💡 Core Intuition

A 90° clockwise rotation can be broken into two simple steps:

    Step 1: Transpose the matrix   (flip over the main diagonal)
    Step 2: Reverse each row       (mirror horizontally)

> 🪞 **Analogy:** Imagine folding a photo along its diagonal crease, then flipping it horizontally. The result is the same as rotating it 90° clockwise.

---

## 🤔 Why Transpose + Reverse = 90° Rotation?

For any element at position `(i, j)` in the original matrix:
- After a 90° clockwise rotation, it lands at `(j, n-1-i)`
- **Transpose** moves `(i,j)` → `(j,i)`
- **Row reverse** moves `(j,i)` → `(j, n-1-i)` ✅

    Original → Transpose → Reverse Each Row → 90° Rotated

---

## 🪜 Algorithm Steps

1. 🔀 **Transpose** — swap `matrix[i][j]` with `matrix[j][i]` for all `j > i`
   - Note: start `j` from `i` to avoid double-swapping
2. ↔️ **Reverse** — reverse each row independently

---

## 🧩 Code Walkthrough

### Dry Run Example

    Original:          After Transpose:     After Row Reverse:
    1  2  3            1  4  7              7  4  1
    4  5  6     →      2  5  8      →       8  5  2
    7  8  9            3  6  9              9  6  3

    ✅ 90° Clockwise rotation achieved!

### Why `j` starts from `i` (not 0)?

    If j started from 0, each pair (i,j) and (j,i) would be swapped TWICE
    → ending up back in the original position!

    Starting j from i means:
    - j == i  → swap with itself (no-op, safe)
    - j > i   → each pair swapped exactly once ✅

### Pseudocode

    rotate(matrix):
        n = matrix.size()

        // Step 1: Transpose
        for i from 0 to n-1:
            for j from i to n-1:
                swap(matrix[i][j], matrix[j][i])

        // Step 2: Reverse each row
        for i from 0 to n-1:
            reverse(matrix[i])

### Full C++ Solution

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();

        // Step 1: Transpose (swap across main diagonal)
        for (int i = 0; i < n; i++)
            for (int j = i; j < n; j++)
                swap(matrix[i][j], matrix[j][i]);

        // Step 2: Reverse each row
        for (int i = 0; i < n; i++)
            reverse(matrix[i].begin(), matrix[i].end());
    }
};
```

## 📊 Complexity Analysis

| Metric | Complexity | Reason |
|--------|-----------|--------|
| ⏱️ **Time** | O(N²) | Every cell visited once in transpose + once in reverse |
| 🧠 **Space** | ✅ O(1) | Done fully in-place, no extra matrix used |

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **Transpose + Reverse = 90° clockwise** — clean two-step trick |
| 2 | Inner loop starts at `j = i` to avoid **double swapping** |
| 3 | For **90° counter-clockwise**: reverse each row first, then transpose |
| 4 | For **180° rotation**: reverse each row + reverse the entire matrix vertically |

---

## 🔁 Rotation Variants

| Rotation | Steps |
|----------|-------|
| 90° Clockwise | Transpose → Reverse each row |
| 90° Counter-Clockwise | Reverse each row → Transpose |
| 180° | Reverse each row → Reverse entire matrix (top-bottom) |

---

## ⚠️ Common Mistakes

- ❌ **Starting `j` from `0`** instead of `i` → each element swapped twice = no change
- ❌ **Creating a new matrix** → violates the in-place constraint
- ❌ **Reversing columns instead of rows** after transpose → gives counter-clockwise result
