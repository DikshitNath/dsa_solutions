# 📊 Top K Frequent Elements

> **Platform:** LeetCode | **Topic:** Array / HashMap | **Technique:** Frequency Map + Custom Sort

**Question Link:** [https://leetcode.com/problems/top-k-frequent-elements/](https://leetcode.com/problems/top-k-frequent-elements/)

---

## 📌 Problem Summary

Given an integer array `nums` and an integer `k`, return the `k` most frequent elements in any order.

    Input:  nums = [1,1,1,2,2,3], k = 2
    Output: [1, 2]

---

## 💡 Core Intuition

Count the frequency of each element using a hash map. Then sort elements by frequency in descending order and pick the top `k`.

> 📋 **Analogy:** Count how many votes each candidate gets, sort by votes descending, announce the top k winners.

---

## 🪜 Algorithm Steps

1. 🗺️ Build `frq` map: count occurrences of each element
2. 📦 Convert map to `vector<pair<int,int>>` for sorting
3. 🔽 Sort by frequency **descending** using custom comparator
4. 🏆 Take first `k` elements' keys into `ans`
5. 📤 Return `ans`

---

## 🧩 Code Walkthrough

### Dry Run Example

    nums = [1, 1, 1, 2, 2, 3],  k = 2

    frq = {1:3, 2:2, 3:1}

    vec = [(1,3), (2,2), (3,1)]

    After sort (by freq desc):
    vec = [(1,3), (2,2), (3,1)]

    Take first k=2:
    ans = [1, 2] ✅

### Custom Comparator Explained

    sort(vec, [](auto& a, auto& b){
        return a.second > b.second;   // sort by frequency, high → low
    })

    a.second = frequency of element a
    b.second = frequency of element b
    a.second > b.second → descending order

### Pseudocode

    topKFrequent(nums, k):
        build frq map: element → count

        convert frq to vec of (element, count) pairs
        sort vec by count descending

        return first k elements' keys

### Full C++ Solution

```cpp
class Solution {
public:
    vector<int> topKFrequent(vector<int>& nums, int k) {
        unordered_map<int, int> frq;
        for (int x : nums) frq[x]++;   // count frequencies

        // convert map to sortable vector of pairs
        vector<pair<int,int>> vec(frq.begin(), frq.end());

        // sort by frequency descending
        sort(vec.begin(), vec.end(), [](auto& a, auto& b) {
            return a.second > b.second;
        });

        // collect top k elements
        vector<int> ans;
        for (int i = 0; i < k; i++)
            ans.push_back(vec[i].first);

        return ans;
    }
};
```

## 📊 Complexity Analysis

| Metric | Complexity | Reason |
|--------|-----------|--------|
| ⏱️ **Time** | O(N log N) | Building map O(N) + sorting O(U log U) where U = unique elements ≤ N |
| 🧠 **Space** | O(N) | Map + vector both store at most N elements |

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | Map → vector conversion enables **custom sorting** by frequency |
| 2 | Lambda `a.second > b.second` sorts **descending** by count |
| 3 | `vec[i].first` is the **element**, `vec[i].second` is the **frequency** |
| 4 | This approach is simple but not optimal — see heap approach below |

---

## ⚠️ Common Mistakes

- ❌ **Sorting ascending** (`a.second < b.second`) → takes least frequent k elements
- ❌ **Pushing `vec[i].second`** (frequency) instead of `vec[i].first` (element) into ans
- ❌ **Sorting the original map** → maps can't be directly sorted in C++

---

## 🚀 Optimal O(N log K) — Min Heap Approach

Instead of sorting all elements, maintain a min-heap of size `k`:

    for each (element, freq) in frq:
        push into min-heap (by freq)
        if heap.size() > k → pop minimum

    heap always holds the k most frequent elements

    Time: O(N log K)  — better when k << N
    Space: O(N + K)

## 🚀 O(N) — Bucket Sort Approach

    Create buckets where index = frequency (max freq = N)
    Put each element in its frequency bucket
    Scan from highest bucket down, collect k elements

    Time: O(N) | Space: O(N)
