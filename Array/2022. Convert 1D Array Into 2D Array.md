# 🔢 Convert 1D Array Into 2D Array

> **Platform:** LeetCode 2022 | **Topic:** Arrays / Math | **Techniques:** Index Math (i/n, i%n) + Nested Loop (idx++)

**Question Link:** https://leetcode.com/problems/convert-1d-array-into-2d-array/

---

## 📌 Problem Summary

Given a 1D array `original` and integers `m`, `n`, convert it into a 2D array with `m` rows and `n` columns, filling **row by row**. If impossible, return `{}`.

**Examples:**

- Input: `original = [1,2,3,4]`, `m = 2`, `n = 2` → Output: `[[1,2],[3,4]]`
- Input: `original = [1,2,3]`, `m = 1`, `n = 3` → Output: `[[1,2,3]]`
- Input: `original = [1,2]`, `m = 1`, `n = 1` → Output: `[]`

---

## 💡 Core Intuition

A 1D array of size `k` can form an `m×n` 2D array **only if `k == m*n`**. If valid, map each 1D index `i` to 2D position `(i/n, i%n)` — or equivalently, fill row by row using a running index.

> 📐 **Key formula:** For a matrix with `n` columns, element at 1D index `i` maps to row `i/n`, column `i%n`.

---

## 🔵 Approach 1 — Index Math (i/n, i%n)

### 💡 Intuition

For each element at 1D index `i`, compute its 2D position directly using integer division and modulo.

**Example with n=3 columns:**
- `i=0` → `row=0/3=0, col=0%3=0`
- `i=1` → `row=1/3=0, col=1%3=1`
- `i=2` → `row=2/3=0, col=2%3=2`
- `i=3` → `row=3/3=1, col=3%3=0` ← new row ✅

### 💻 Solution

```cpp
class Solution {
public:
    vector<vector<int>> construct2DArray(vector<int>& original, int m, int n) {
        if (original.size() != (size_t)(m * n)) return {};

        vector<vector<int>> ans(m, vector<int>(n));

        for (int i = 0; i < (int)original.size(); i++) {
            ans[i / n][i % n] = original[i];
        }

        return ans;
    }
};
```

### 📊 Complexity

| Metric | Complexity | Reason |
|--------|-----------|--------|
| ⏱️ Time | O(m×n) | Visit every element once |
| 🧠 Space | O(m×n) | Output array |

## 🟢 Approach 2 — Nested Loop + `idx++`

### 💡 Intuition

Use a running pointer `idx` into `original`. Outer loop = rows, inner loop = columns. Fill sequentially.

### 💻 Solution

```cpp
class Solution {
public:
    vector<vector<int>> construct2DArray(vector<int>& original, int m, int n) {
        if (original.size() != (size_t)(m * n)) return {};

        vector<vector<int>> ans(m, vector<int>(n));
        int idx = 0;

        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                ans[i][j] = original[idx++];

        return ans;
    }
};
```

### 📊 Complexity

| Metric | Complexity | Reason |
|--------|-----------|--------|
| ⏱️ Time | O(m×n) | Visit every element once |
| 🧠 Space | O(m×n) | Output array |

## 🧩 Dry Run — Both Approaches

**Example:** `original = [1,2,3,4,5,6]`, `m = 2`, `n = 3`

**Validity check:** `6 == 2*3 = 6` ✅ Proceed

### Index Math Approach:

| i | i/n | i%n | Position | Value |
|---|-----|-----|----------|-------|
| 0 | 0/3 = 0 | 0%3 = 0 | ans[0][0] | 1 |
| 1 | 1/3 = 0 | 1%3 = 1 | ans[0][1] | 2 |
| 2 | 2/3 = 0 | 2%3 = 2 | ans[0][2] | 3 |
| 3 | 3/3 = 1 | 3%3 = 0 | ans[1][0] | 4 |
| 4 | 4/3 = 1 | 4%3 = 1 | ans[1][1] | 5 |
| 5 | 5/3 = 1 | 5%3 = 2 | ans[1][2] | 6 |

**Result:** `[[1,2,3],[4,5,6]]` ✅

### Nested Loop Approach:

```
idx = 0
i=0 (row 0): j=0→ans[0][0]=1, j=1→ans[0][1]=2, j=2→ans[0][2]=3
i=1 (row 1): j=0→ans[1][0]=4, j=1→ans[1][1]=5, j=2→ans[1][2]=6
```

**Result:** `[[1,2,3],[4,5,6]]` ✅

| # | Insight |
|---|---------|
| 1 | **`original.size() != m*n`** → only validity check needed |
| 2 | **`i/n` = row, `i%n` = col** — maps 1D index to 2D in one line |
| 3 | Both approaches are O(m×n) — pick based on readability preference |
| 4 | **Approach 1** is more elegant (no extra variable); **Approach 2** is more explicit |
| 5 | `(size_t)` cast avoids signed/unsigned comparison warning |

## ⚠️ Common Mistakes

- ❌ **Skipping size check** → accessing out-of-bounds → runtime error
- ❌ **`i/m` instead of `i/n`** → dividing by rows instead of cols → wrong mapping
- ❌ **`i%m` instead of `i%n`** → wrong column index
- ❌ **Signed/unsigned comparison** → `original.size()` returns `size_t` → compare carefully

## 🔁 The Index Formula — Why It Works

**1D array laid flat, n=3 columns:**

```
Index:  0  1  2  |  3  4  5  |  6  7  8
       [─────row 0─────][─────row 1─────][─────row 2─────]
```

**Formula:**
- **Row** = index / n (how many complete rows fit before this index)
- **Col** = index % n (position within the current row)

**Example:** `i=4: row = 4/3 = 1, col = 4%3 = 1` → `ans[1][1]` ✅

## 🆚 Approach 1 vs Approach 2

| Feature | Index Math (i/n, i%n) | Nested Loop (idx++) |
|---------|----------------------|---------------------|
| Extra variable | ❌ None | ✅ `idx` needed |
| Readability | Shows math insight | More intuitive loop |
| Flexibility | Works for non-sequential fills | Sequential only |
| Interview value | Shows formula knowledge | Shows clean iteration |
