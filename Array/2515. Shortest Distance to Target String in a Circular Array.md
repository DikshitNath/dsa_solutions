# 🔄 Shortest Distance to Target String in a Circular Array

> **Platform:** LeetCode 2515 | **Topic:** Arrays | **Technique:** Linear Scan + Circular Distance Formula

**Question Link:** https://leetcode.com/problems/shortest-distance-to-target-string-in-a-circular-array/

---

## 📌 Problem Summary

Given a circular array of strings `words`, a `target` string, and a `startIndex`, return the **shortest distance** to any occurrence of `target` — moving either clockwise or counter-clockwise. Return `-1` if `target` doesn't exist.

```
words=["hello","i","am","hello","i"], target="hello", startIndex=1
  Occurrences at index 0 and 3
  From index 1:
    To index 0: clockwise=1, counterclockwise=n-1=4 → min=1
    To index 3: clockwise=2, counterclockwise=n-2=3 → min=2
  Answer: min(1,2) = 1
```

---

## 💡 Core Intuition

Scan the array linearly. For each index where `words[i] == target`, compute both the **direct** and **circular (wrap-around)** distances from `startIndex`. Track the global minimum.

> 🕰️ **Analogy:** A clock face — you can go clockwise or counter-clockwise to reach any hour. The shorter path is the answer.

---

## 🔁 The Circular Distance Formula

```
Direct distance:    d = abs(i - startIndex)
Wrap-around dist:  circularD = n - d

Why n - d?
  Going the other way around a circle of n elements
  = total circle - direct path
  = n - d

Min distance to index i = min(d, n - d)
```

```
Example: n=5, startIndex=1, target at i=4
  d = |4-1| = 3       (clockwise: 1→2→3→4)
  circularD = 5-3 = 2 (counter: 1→0→4)
  Answer: min(3,2) = 2 ✅
```

---

## 🪜 Algorithm Steps

1. 🏁 `ans = INT_MAX`
2. 🔁 For each `i` from `0` to `n-1`:
   - If `words[i] == target`:
     - `d = abs(i - startIndex)`
     - `circularD = n - d`
     - `ans = min(ans, d, circularD)`
3. 📤 Return `ans == INT_MAX ? -1 : ans`

---

## 🧩 Dry Run

```
words = ["a","b","c","a","b"], target="a", startIndex=2, n=5

i=0: words[0]="a" == target ✅
  d = |0-2| = 2
  circularD = 5-2 = 3
  ans = min(INT_MAX, 2, 3) = 2

i=1: words[1]="b" ≠ target → skip
i=2: words[2]="c" ≠ target → skip

i=3: words[3]="a" == target ✅
  d = |3-2| = 1
  circularD = 5-1 = 4
  ans = min(2, 1, 4) = 1

i=4: words[4]="b" ≠ target → skip

ans=1 ≠ INT_MAX → return 1 ✅
```

## 💻 Full C++ Solution

```cpp
class Solution {
public:
    int closestTarget(vector<string>& words, string target, int startIndex) {
        int n = words.size();
        int ans = INT_MAX;

        for (int i = 0; i < n; i++) {
            if (words[i] == target) {
                int d = abs(i - startIndex);
                int circularD = n - d;
                ans = min({ans, d, circularD});
            }
        }

        return ans == INT_MAX ? -1 : ans;
    }
};
```

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **`circularD = n - d`** — wrap-around distance is always `n` minus the direct distance |
| 2 | **`min({ans, d, circularD})`** — initializer list `min` cleanly handles 3-way comparison |
| 3 | **`INT_MAX` sentinel** — distinguishes "not found" from distance 0 (same index) |
| 4 | **`d` can be 0** — if `startIndex` itself contains `target`, answer is 0 |
| 5 | **Multiple occurrences** — scan all, track global min (your code handles this correctly ✅) |

---

## ⚠️ Common Mistakes

- ❌ **`circularD = n - abs(i-startIndex)` only** — forgetting to also track direct `d`
- ❌ **Returning first match** — multiple occurrences may have a shorter one later
- ❌ **`ans == 0` early return** — while safe to add, `d=0` only when `words[startIndex]==target`
- ❌ **`return -1` unconditionally at end** — must check `ans == INT_MAX` first

---

## 🔁 Why `min({ans, d, circularD})` Works

```cpp
// Standard min takes exactly 2 args
min(a, b)

// min with initializer list takes any number
min({a, b, c})    // C++11 and later ✅

// Equivalent manual version:
ans = min(ans, min(d, circularD));
```

Both are correct — the initializer list form is cleaner for 3+ values.

---

## 🔁 Edge Cases

```
1. target == words[startIndex]:
   d = |startIndex - startIndex| = 0
   circularD = n - 0 = n
   min(0, n) = 0 → return 0 ✅

2. target not in words:
   ans stays INT_MAX
   return -1 ✅

3. Single occurrence at opposite end:
   n=6, startIndex=0, target at i=3
   d=3, circularD=3 → min=3 (equidistant both ways) ✅

4. n=1, startIndex=0, words[0]==target:
   d=0, circularD=1 → return 0 ✅
```
