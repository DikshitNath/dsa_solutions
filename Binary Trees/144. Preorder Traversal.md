# 🌳 Binary Tree Preorder Traversal

> **Platform:** LeetCode | **Topic:** Binary Tree | **Technique:** Recursive DFS

**Question Link:** [https://leetcode.com/problems/binary-tree-preorder-traversal/](https://leetcode.com/problems/binary-tree-preorder-traversal/)

---

## 📌 Problem Summary

Given the `root` of a binary tree, return the **preorder traversal** of its node values as an array.

    Preorder = Root → Left → Right

---

## 💡 Core Intuition

Process the **current node first**, then recursively visit the **left subtree**, then the **right subtree**. The root is always the first element in the output.

> 🗺️ **Analogy:** Exploring a building — note the floor you're on first, then fully explore the left wing, then the right wing.

---

## 🤔 Traversal Orders Recap

| Order | Sequence | When Root is Processed |
|-------|----------|------------------------|
| **Preorder** | Root → Left → Right | ✅ First |
| **Inorder** | Left → Root → Right | Middle |
| **Postorder** | Left → Right → Root | Last |

Preorder is useful for **tree serialization/copying** — you always know the root before its children.

---

## 🪜 Algorithm Steps

1. 🚫 Base case: if `root == null` → return
2. ✅ Push `root->val` into `ans` **(process first)**
3. ↙️ Recurse into `root->left`
4. ↘️ Recurse into `root->right`

### Comparing All Three Traversals on Same Tree

         4
        / \
       2   6
      / \ / \
     1  3 5  7

    Preorder  (R→L→R): [4, 2, 1, 3, 6, 5, 7]   ← root first
    Inorder   (L→R→R): [1, 2, 3, 4, 5, 6, 7]   ← sorted (BST)
    Postorder (L→R→R): [1, 3, 2, 5, 7, 6, 4]   ← root last

### Pseudocode

    preorder(root, ans):
        if root is null → return

        ans.push(root.val)            // ✅ process root FIRST
        preorder(root.left, ans)      // ↙️ then left
        preorder(root.right, ans)     // ↘️ then right

### Full C++ Solution

```cpp
class Solution {
public:
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> ans;
        preorder(root, ans);
        return ans;
    }

    void preorder(TreeNode* root, vector<int>& ans) {
        if (!root) return;                  // base case

        ans.push_back(root->val);           // process current node FIRST
        preorder(root->left, ans);          // left subtree
        preorder(root->right, ans);         // right subtree
    }
};
```

| Metric | Complexity | Reason |

| 🧠 **Space** | O(H) | Recursion stack = tree height; O(log N) balanced, O(N) skewed |

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | Root is **always the first element** in preorder output |
| 2 | Preorder reconstructs the tree — used in **serialization** |
| 3 | Pass `ans` by **reference** to avoid copying on every recursive call |
| 4 | Only difference from inorder: `push_back` moved **before** left recursion |

---

## ⚠️ Common Mistakes

- ❌ **Pushing root after left call** → becomes Inorder, not Preorder
- ❌ **Passing `ans` by value** → result lost after each call returns
- ❌ **Missing base case** → null pointer dereference on leaf children

## 🔄 Iterative Version (Follow-up)

Preorder is the easiest traversal to implement iteratively:

    iterativePreorder(root):
        if root is null → return
        stack = [root]

        while stack not empty:
            node = stack.pop()
            ans.push(node.val)         // process immediately on pop

            if node.right → stack.push(node.right)   // right pushed first
            if node.left  → stack.push(node.left)    // left on top = processed first

    Note: Push RIGHT before LEFT so that LEFT is on top of stack
    and gets processed first — matching Root→Left→Right order.
