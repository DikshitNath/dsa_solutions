# 📏 Maximum Depth of Binary Tree

> **Platform:** LeetCode | **Topic:** Binary Tree | **Technique:** Recursive DFS (Postorder)

**Question Link:** [https://leetcode.com/problems/maximum-depth-of-binary-tree/](https://leetcode.com/problems/maximum-depth-of-binary-tree/)

---

## 📌 Problem Summary

Given the `root` of a binary tree, return its **maximum depth** — the number of nodes along the longest path from the root down to the farthest leaf.

    Tree:        4
                / \
               2   6
              / \
             1   3

    Max Depth = 3  (path: 4 → 2 → 1  or  4 → 2 → 3)

---

## 💡 Core Intuition

The depth of any node = `1 + max(depth of left subtree, depth of right subtree)`. Recursively ask each subtree for its depth, take the larger one, and add 1 for the current node.

> 🏔️ **Analogy:** To find the tallest branch of a tree, ask each sub-branch how tall it is. Take the taller one and add 1 for the trunk you're standing on.

---

## 🤔 Why Postorder?

We need **children's depths before computing the parent's depth** — that's exactly postorder (Left → Right → Root). The result bubbles up from the leaves to the root.

    Leaf node    → returns 1  (0 from both null children + 1 for itself)
    Null node    → returns 0  (base case)
    Every other  → 1 + max(left, right)

---

## 🪜 Algorithm Steps

1. 🚫 Base case: if `root == null` → return `0`
2. 📏 Recursively get `lh = maxDepth(root->left)`
3. 📏 Recursively get `rh = maxDepth(root->right)`
4. 📤 Return `1 + max(lh, rh)`

### Pseudocode

    maxDepth(root):
        if root is null → return 0       // base case

        return 1 + max(lh, rh)           // current node adds 1

### Full C++ Solution

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (!root) return 0;                    // base case: null = depth 0

        int lh = maxDepth(root->left);          // left subtree depth
        int rh = maxDepth(root->right);         // right subtree depth

        return 1 + max(lh, rh);                 // add 1 for current node
    }
};
```

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **Base case returns 0** — null contributes no depth, leaf gets `1+max(0,0)=1` automatically |
| 2 | This is **postorder** — children computed before parent |
| 3 | For a **single node tree**, returns `1+max(0,0) = 1` ✅ |
| 4 | Same logic powers many tree problems: height, diameter, path sum, balance check |

## ⚠️ Common Mistakes

- ❌ **Returning 1 for null** instead of 0 → overcounts depth by 1
- ❌ **Using `+` instead of `max`** → adds both subtree depths (that's diameter, not depth)
- ❌ **Forgetting `+1`** → doesn't count the current node itself

---

## 🔁 BFS Alternative

Depth = number of levels → count BFS levels:

    maxDepth(root):
        if null → return 0
        queue.push(root)
        depth = 0

        while queue not empty:
            size = queue.size()
            for i in 0 to size-1:
                node = queue.pop()
                push children if exist
            depth++          // one full level processed

        return depth

    Time: O(N) | Space: O(W) where W = max width
