# 🔍 Find Bottom Left Tree Value

> **Platform:** LeetCode 513 | **Topic:** Trees / BFS | **Technique:** Level Order — Track First Node of Each Level

**Question Link:** https://leetcode.com/problems/find-bottom-left-tree-value/

---

## 📌 Problem Summary

Given the `root` of a binary tree, return the **leftmost value in the last row** (bottom-most level) of the tree.

```
        1
       / \
      2   3
     /   / \
    4   5   6
       /
      7

Bottom level: [4, 7, 6]
Leftmost     = 4... wait:

Actually bottom level = [7, 6] → no, let's trace:
Level 1: [1]
Level 2: [2, 3]
Level 3: [4, 5, 6]
Level 4: [7]

Bottom left = 7 ✅
```

---

## 💡 Core Intuition

BFS processes level by level. For every level, **capture the first node's value** (`q.front()->val`) before draining it. By the time the queue is empty, `ans` holds the first node of the **last level** — which is the bottom-left value.

> 📸 **Analogy:** Take a photo of the leftmost person on each floor as you go up. When you reach the top floor and the building is empty, the last photo you took is the answer.

---

## 🤔 Why Capture `q.front()` Before the Inner Loop?

```
Before inner loop starts:
  queue = [first_node_of_level, ..., last_node_of_level]
  q.front() = first node of this level = leftmost node ✅

After inner loop:
  queue = [nodes of NEXT level]
  q.front() = first node of next level (we'd be one level ahead) ❌
```

By snapshotting `ans = q.front()->val` **before** `while(n--)`, we capture the leftmost node of the current level. This gets overwritten each level — so after the last level, `ans` holds the leftmost of the bottom row.

---

## 🤔 Why Not Capture Inside the Inner Loop?

```cpp
// ❌ Inside loop — would need an index check
while (n--) {
    if (i == 0) ans = node->val;  // extra condition every iteration
}

// ✅ Before loop — clean, no extra condition
ans = q.front()->val;             // front of queue = leftmost of level
while (n--) { ... }
```

`q.front()` before the loop directly gives the first (leftmost) node — no index tracking needed.

---

## 🪜 Algorithm Steps

1. 🏁 Push `root` into queue
2. 🔁 While queue not empty:
   - **Snapshot `ans = q.front()->val`** (leftmost of current level)
   - Snapshot `n = q.size()`
   - 🔁 Process exactly `n` nodes:
     - Pop node
     - Push left then right children
3. 📤 Return `ans` (leftmost of last level)

## 💻 Full C++ Solution

```cpp
class Solution {
public:
    int findBottomLeftValue(TreeNode* root) {
        int ans = root->val;          // safe: problem guarantees non-empty tree
        queue<TreeNode*> q;
        q.push(root);

        while (!q.empty()) {
            int n = q.size();

            ans = q.front()->val;     // leftmost node of current level

            while (n--) {
                TreeNode* node = q.front();
                q.pop();

                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
        }
        return ans;
    }
};
```

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **`ans = q.front()->val` before inner loop** — captures leftmost of current level |
| 2 | **Overwrites each level** — final value is leftmost of last level ✅ |
| 3 | **No null root check needed** — problem guarantees at least one node |
| 4 | **Children pushed left-first** — maintains left-to-right BFS order |
| 5 | Elegant O(1) extra logic — no index tracking, no conditionals inside loop |

## ⚠️ Common Mistakes

- ❌ **`ans = q.front()` after inner loop** → queue now has next level's nodes → off by one level
- ❌ **Capturing inside loop with `i==0` check** → works but verbose; `q.front()` before loop is cleaner
- ❌ **Pushing right before left** → rightmost node becomes front of next level → wrong answer
- ❌ **`int ans = 1`** → arbitrary init (your code had this); safe only because it's always overwritten before return, but `root->val` is more semantically correct

## 🔁 `ans = q.front()` Placement — Critical Detail

```
Queue state at start of each iteration:

Iteration 1: queue = [1]        → ans=1,  drain → queue=[2,3]
Iteration 2: queue = [2,3]      → ans=2,  drain → queue=[4,5,6]
Iteration 3: queue = [4,5,6]    → ans=4,  drain → queue=[7]
Iteration 4: queue = [7]        → ans=7,  drain → queue=[]

Loop ends. ans=7 = leftmost of last level ✅

If ans captured AFTER inner loop:
Iteration 1: drain → queue=[2,3]   → ans=2   ← one level ahead ❌
```

## 🆚 BFS vs DFS for Bottom Left Value

| Feature | BFS (this) | DFS |
|---------|-----------|-----|
| Approach | Track first node per level | Track deepest first-visited node |
| Intuition | Natural — leftmost of last level | Right-first DFS, update on new max depth |
| Code complexity | Simple | Slightly tricky |
| Space | O(W) queue | O(H) call stack |

**DFS approach (for reference):**
```cpp
int maxDepth = 0, ans = root->val;

void dfs(TreeNode* node, int depth) {
    if (!node) return;
    if (depth > maxDepth) {
        maxDepth = depth;
        ans = node->val;    // first node at new deepest level = leftmost
    }
    dfs(node->left,  depth + 1);   // left first!
    dfs(node->right, depth + 1);
}
```
