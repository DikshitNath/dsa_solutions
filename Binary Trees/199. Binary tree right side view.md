# 👁️ Binary Tree Right Side View

> **Platform:** LeetCode 199 | **Topic:** Trees | **Techniques:** BFS (Level Order) + DFS (Modified Preorder)

**Question Link:** https://leetcode.com/problems/binary-tree-right-side-view/

---

## 📌 Problem Summary

Given the `root` of a binary tree, imagine standing on the **right side** of it. Return the values of the nodes you can see ordered **top to bottom** — i.e., the **rightmost node at each level**.

```
        1         ← see 1
       / \
      2   3       ← see 3
       \   \
        5   4     ← see 4

Output: [1, 3, 4]
```

---

## 🔵 Approach 1 — BFS (Level Order Traversal)

### 💡 Intuition

Process the tree **level by level**. At each level, drain the entire queue — the **last node dequeued** is the rightmost visible node. Capture it after the inner loop.

> 🎥 **Analogy:** Photograph each floor of a building from the right — the rightmost person on each floor is who you capture.

### 🪜 Algorithm

1. Push `root` into queue
2. While queue not empty:
   - Snapshot level size `n = q.size()`
   - Process all `n` nodes (inner while loop)
   - After inner loop, `node` holds the **last (rightmost) node of this level**
   - Push its value to `ans`
3. Return `ans`

### 🧩 Dry Run

```
Tree:       1
           / \
          2   3
           \
            5

Level 1: queue=[1]     → drain → node=1 → ans=[1]
Level 2: queue=[2,3]   → drain → node=3 → ans=[1,3]
Level 3: queue=[5]     → drain → node=5 → ans=[1,3,5]

Output: [1, 3, 5] ✅
```

### 💻 BFS Solution

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        if (!root) return {};
        vector<int> ans;

        queue<TreeNode*> q;
        q.push(root);

        while (!q.empty()) {
            TreeNode* node;
            int n = q.size();           // snapshot current level size

            while (n--) {
                node = q.front();
                q.pop();

                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
            ans.push_back(node->val);   // last node after inner loop = rightmost
        }

        return ans;
    }
};
```

### ⚙️ Why `node` Is Declared Outside Inner Loop

`node` is declared in the **outer loop** scope so it retains the value of the **last iteration** of the inner loop. If declared inside `while(n--)`, it would go out of scope before `ans.push_back(node->val)`.

```cpp
TreeNode* node;       // ← outer scope, survives after inner while ends
while (n--) {
    node = q.front(); // ← keeps getting overwritten
    q.pop();
    ...
}
ans.push_back(node->val);  // ← node = last node of this level ✅
```

## 🟢 Approach 2 — DFS (Modified Right-First Preorder)

### 💡 Intuition

Do a **right-first preorder traversal** (Root → Right → Left). The **first time** you visit a new level, it's always the rightmost node at that level — because you always go right before left.

> 🌲 **Analogy:** Always take the rightmost path first in a maze — the first time you reach a new depth, you're guaranteed to be on the rightmost branch.

### 🪜 Algorithm

1. Recurse with `(node, level, ans)`
2. If `ans.size() < level` → first visit to this level → push `root->val`
3. Recurse **right first**, then left
4. Incrementing `level` at each recursive call tracks depth

### 🧩 Dry Run

```
Tree:       1
           / \
          2   3
           \
            5

preOrder(1, level=1):
  ans.size()=0 < 1 → ans=[1]
  → preOrder(3, level=2):
      ans.size()=1 < 2 → ans=[1,3]
      → preOrder(null, level=3): return
      → preOrder(null, level=3): return
  → preOrder(2, level=2):
      ans.size()=2, level=2 → NOT < 2 → skip (3 already recorded)
      → preOrder(5, level=3):
          ans.size()=2 < 3 → ans=[1,3,5]
      → preOrder(null, level=3): return

Output: [1, 3, 5] ✅
```

### 💻 DFS Solution

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> ans;
        preOrder(root, 1, ans);
        return ans;
    }

    void preOrder(TreeNode* root, int level, vector<int>& ans) {
        if (!root) return;

        if (ans.size() < level)          // first visit to this level
            ans.push_back(root->val);    // rightmost node (right visited first)

        preOrder(root->right, level + 1, ans);   // right first!
        preOrder(root->left,  level + 1, ans);   // then left
    }
};
```

### ⚙️ Why `ans.size() < level` Works

```
level 1 → ans.size()=0 < 1 ✅ push
level 2 → ans.size()=1 < 2 ✅ push
level 3 → ans.size()=2 < 3 ✅ push

Second visit to level 2 (from left subtree):
  ans.size()=2, level=2 → 2 < 2 is false ❌ skip ✅ correct!
```

The condition acts as a **"first visit to this level"** guard. Since right is always visited first, the first visit is always the rightmost node.

## 📊 Complexity Analysis

| | BFS | DFS |
|-|-----|-----|
| ⏱️ **Time** | O(N) | O(N) |
| 🧠 **Space** | O(W) — max width | O(H) — height |
| Best space for | Tall/skinny trees | Wide/bushy trees |
| Worst case space | O(N/2) perfect tree | O(N) skewed tree |

> 📝 For a **balanced tree**: BFS space = O(N/2), DFS space = O(log N) → **DFS wins on space**
> For a **skewed tree**: DFS space = O(N) due to call stack → **BFS wins on space**

---

## 🆚 BFS vs DFS — Side by Side

| Feature | BFS | DFS |
|---------|-----|-----|
| Traversal order | Level by level | Root → Right → Left |
| Rightmost capture | Last node after draining level | First node at each new level |
| Uses | Queue | Recursion stack |
| Intuition | Natural level processing | Clever right-first ordering |
| Easier to extend | ✅ Level-based problems | ❌ Needs modification |
| Interview preference | More intuitive to explain | Shows deeper tree understanding |

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | **BFS**: `node` after inner loop = rightmost of that level |
| 2 | **DFS**: right-first traversal + `ans.size() < level` = rightmost guarantee |
| 3 | Both are O(N) time — choose based on space constraints |
| 4 | DFS `level` starts at `1`, not `0` — aligns with `ans.size()` guard |
| 5 | BFS is more natural; DFS is more elegant |

## ⚠️ Common Mistakes

- ❌ **BFS: `node` declared inside inner loop** → out of scope for `ans.push_back`
- ❌ **DFS: left before right** → leftmost node recorded, not rightmost
- ❌ **DFS: `level` starts at 0** → `ans.size() < 0` never true → nothing recorded
- ❌ **DFS: `ans[level]` direct access** → out of bounds; use `push_back` with size check
