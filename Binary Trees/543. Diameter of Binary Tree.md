# 📐 Diameter of Binary Tree

> **Platform:** LeetCode | **Topic:** Binary Tree | **Technique:** Recursive DFS (Postorder)

**Question Link:** [https://leetcode.com/problems/diameter-of-binary-tree/](https://leetcode.com/problems/diameter-of-binary-tree/)

---

## 📌 Problem Summary

Given the `root` of a binary tree, return the **diameter** — the length of the longest path between any two nodes. The path may or may not pass through the root, and length is measured in **number of edges**.

    Tree:        1
                / \
               2   3
              / \
             4   5

    Diameter = 3  (path: 4 → 2 → 1 → 3  or  5 → 2 → 1 → 3)

---

## 💡 Core Intuition

At every node, the longest path **passing through it** = `leftHeight + rightHeight` (edges going down both sides). Track the global maximum of this across all nodes using a reference variable `dia`.

> 🌉 **Analogy:** At each node, you're building a bridge using the longest left arm and longest right arm. The widest bridge across any node is the diameter.

---

## 🤔 Diameter vs Depth — Key Distinction

| | Formula | What it measures |
|--|---------|-----------------|
| **Depth** | `1 + max(lh, rh)` | Longest path from node **downward** (returned up) |
| **Diameter** | `lh + rh` | Longest path **through** a node (tracked globally) |

The function **returns depth** (for parent's use) but **updates diameter** (as a side effect) at each node. Both computations happen in the same DFS pass.

---

## 🪜 Algorithm Steps

1. 🏁 Initialize `dia = 0`
2. 🔁 Run DFS (postorder) on each node:
   - Get `lh = dfs(left)` and `rh = dfs(right)`
   - Update `dia = max(dia, lh + rh)` ← **widest path through this node**
   - Return `1 + max(lh, rh)` ← **height for parent's use**
3. 📤 Return `dia`

## 🧩 Code Walkthrough

### Dry Run Example

         1
        / \
       2   3
      / \
     4   5

    dfs(4): lh=0, rh=0 → dia=max(0,0)=0,  return 1
    dfs(5): lh=0, rh=0 → dia=max(0,0)=0,  return 1
    dfs(2): lh=1, rh=1 → dia=max(0,1+1)=2, return 2
    dfs(3): lh=0, rh=0 → dia=max(2,0)=2,  return 1
    dfs(1): lh=2, rh=1 → dia=max(2,2+1)=3, return 3

    Output: 3 ✅

### Why Pass `dia` by Reference?

    dia is a GLOBAL maximum across ALL nodes.
    Passing by reference lets every recursive call
    update the same variable — no need to return it
    or merge results manually.

    The function returns HEIGHT (int) for the parent,
    while updating DIAMETER (&dia) as a side effect.

### Pseudocode

    dfs(root, dia):
        if root is null → return 0

        lh = dfs(root.left,  dia)       // left subtree height
        rh = dfs(root.right, dia)       // right subtree height

        dia = max(dia, lh + rh)         // widest path through this node

        return 1 + max(lh, rh)          // height returned to parent

    diameterOfBinaryTree(root):
        dia = 0
        dfs(root, dia)
        return dia

### Full C++ Solution

```cpp
class Solution {
public:
    int diameterOfBinaryTree(TreeNode* root) {
        int dia = 0;
        dfs(root, dia);
        return dia;
    }

    int dfs(TreeNode* root, int& dia) {
        if (!root) return 0;                    // base case

        int lh = dfs(root->left,  dia);         // left height
        int rh = dfs(root->right, dia);         // right height

        dia = max(dia, lh + rh);                // update diameter at this node

        return 1 + max(lh, rh);                 // return height to parent
    }
};
```

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | Diameter at a node = `lh + rh` (edges, not nodes) |
| 2 | The function **returns height** but **tracks diameter** — two jobs in one DFS |
| 3 | `dia` passed by **reference** — acts as a global max across all nodes |
| 4 | Diameter does **not** always pass through root — must check every node |

---

## ⚠️ Common Mistakes

- ❌ **Only checking diameter at root** → misses paths entirely within a subtree
- ❌ **Returning `lh + rh`** instead of `1 + max(lh, rh)` → breaks height calculation for parent
- ❌ **Passing `dia` by value** → each call gets its own copy, global max never updates
- ❌ **Counting nodes instead of edges** → answer off by 1 (edges = nodes in path - 1)

---

## 🔁 Diameter vs Related Formulas

    At every node, compute three things:

    Height   = 1 + max(lh, rh)    → returned upward for parent
    Diameter = lh + rh             → checked against global max
    Balance  = abs(lh - rh) <= 1  → used in "Balanced Binary Tree"

    All three use the exact same postorder DFS skeleton!
