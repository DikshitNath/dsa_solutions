# 🔍 Search a 2D Matrix

> **Platform:** LeetCode 74 | **Topic:** Binary Search | **Technique:** Flatten to 1D Binary Search (Optimal) + Staircase Search

**Question Link:** https://leetcode.com/problems/search-a-2d-matrix/

---

## 📌 Problem Summary

Given an `m×n` matrix where:
- Each row is sorted in non-decreasing order
- The **first element of each row > last element of previous row** (rows connect!)

Return `true` if `target` exists.

```
matrix = [[1,  3,  5,  7],
          [10, 11, 16, 20],
          [23, 30, 34, 60]]

target=3  → true
target=13 → false
```

> 🔑 **Key distinction from LC 240:** The "rows connect" guarantee means the entire matrix is a **single sorted sequence** when read row by row — enabling true O(log M×N) binary search.

## 🔵 Approach 1 — Staircase Search (Your Code)

### 💡 Intuition

Start at top-right corner `(0, n-1)`. Every comparison is decisive:
- `matrix[i][j] > target` → move left (`j--`)
- `matrix[i][j] < target` → move down (`i++`)

### 💻 Solution

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size();
        int n = matrix[0].size();

        int i = 0, j = n - 1;    // top-right corner

        while (i < m && j >= 0) {
            if (matrix[i][j] > target)       j--;
            else if (matrix[i][j] < target)  i++;
            else                             return true;
        }

        return false;
    }
};
```

### 📊 Complexity

| Metric | Complexity |
|--------|-----------|
| ⏱️ Time | O(M + N) |
| 🧠 Space | O(1) |

> ⚠️ Correct but **suboptimal** for LC 74 — doesn't exploit the "rows connect" property.

## 🟢 Approach 2 — Binary Search on Flattened 1D (Optimal)

### 💡 Intuition

Since the matrix is fully sorted when flattened, treat it as a 1D array of size `M×N`. Binary search with index math to convert between 1D and 2D indices:

```
1D index mid → row = mid / n,  col = mid % n
```

### 💻 Solution

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size();
        int n = matrix[0].size();

        int lo = 0, hi = m * n - 1;

        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            int val = matrix[mid / n][mid % n];   // convert 1D → 2D

            if (val == target)      return true;
            else if (val < target)  lo = mid + 1;
            else                    hi = mid - 1;
        }

        return false;
    }
};
```

### 📊 Complexity

| Metric | Complexity |
|--------|-----------|
| ⏱️ Time | O(log(M×N)) ✅ |
| 🧠 Space | O(1) |

## 🧩 Dry Run — Staircase

```
matrix = [[1,  3,  5],
          [10, 11, 16],
          [23, 30, 34]]
target = 11

Start: i=0, j=2 → matrix[0][2]=5

Step 1: 5 < 11 → i++ → i=1, j=2 → matrix[1][2]=16
Step 2: 16 > 11 → j-- → i=1, j=1 → matrix[1][1]=11
Step 3: 11 == 11 → return true ✅

Steps taken: 3 = O(M+N)
```

## 🧩 Dry Run — Binary Search

```
matrix = [[1,  3,  5],
          [10, 11, 16],
          [23, 30, 34]]
target = 11

Flattened: [1, 3, 5, 10, 11, 16, 23, 30, 34]
lo=0, hi=8

Step 1: mid=4, val=matrix[4/3][4%3]=matrix[1][1]=11 → 11==11 → return true ✅

Steps taken: 1 = O(log 9) ≈ 3 comparisons max
```


## 🔁 1D ↔ 2D Index Conversion — The Core Formula

```
Matrix with n columns:

1D index → 2D:
  row = idx / n
  col = idx % n

2D → 1D:
  idx = row * n + col

Example (n=3):
  idx=4 → row=4/3=1, col=4%3=1 → matrix[1][1] ✅
  matrix[2][1] → idx=2*3+1=7 ✅
```

This formula appears in:
- This problem (binary search on matrix)
- Convert 1D → 2D Array (LC 2022, previous notes)
- Spiral Matrix indexing
- Any row-major matrix traversal

## ⚠️ Common Mistakes

- ❌ **Using staircase for LC 74** → correct but misses the stronger O(log MN) bound
- ❌ **Using binary search for LC 240** → flattening doesn't give sorted array there
- ❌ **`(lo+hi)/2`** → integer overflow for large `lo`, `hi`
- ❌ **`mid / m` instead of `mid / n`** → dividing by rows instead of columns → wrong index
