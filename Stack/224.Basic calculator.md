# 🧮 Basic Calculator

> **Platform:** LeetCode | **Topic:** Stack | **Technique:** Stack + Sign Tracking

**Question Link:** [https://leetcode.com/problems/basic-calculator](https://leetcode.com/problems/basic-calculator)

---

## 📌 Problem Summary

Given a string `s` representing a valid mathematical expression with `+`, `-`, `(`, `)` and spaces, evaluate and return its result. **No multiplication or division** — only addition, subtraction, and parentheses.

---

## 💡 Core Intuition

Track a running `result` and a `sign` (+1 or -1). When we hit a `(`, **save the current state** (result + sign) onto the stack and start fresh. When we hit `)`, **restore the saved state** and merge the inner result with it.

> 🗂️ **Analogy:** Parentheses are like opening a sub-problem. You bookmark your current work, solve the sub-problem fresh, then come back and add it to where you left off.

---

## 🤔 Key Variables Explained

| Variable | Role |
|----------|------|
| `result` | Running total for the **current level** (inside current parentheses) |
| `num`    | The number currently being **built digit by digit** |
| `sign`   | `+1` or `-1` — the sign of the **next number to be applied** |
| `stack`  | Saves `{result, sign}` when entering `(`, restored at `)` |

---

## 🪜 Algorithm Steps

1. 🔁 Iterate through each character:
   - ` ` → skip
   - `digit` → build `num` digit by digit (`num = num * 10 + digit`)
   - `+` → flush `num` into `result`, set `sign = +1`
   - `-` → flush `num` into `result`, set `sign = -1`
   - `(` → push `result` and `sign` onto stack, **reset** both
   - `)` → flush `num`, pop saved `sign` and `result`, merge with current
2. ➕ After loop, flush the last `num` into `result`

---

## 🧩 Code Walkthrough

### What "Flush" Means

    flush → result += num * sign
             num = 0

This is done before every operator and closing bracket to commit the current number into the running total.

### Dry Run Example

    Input: "2-(3+4)"

    i=0  ch='2'  → num=2
    i=1  ch='-'  → result += 2*1 = 2,  sign=-1,  num=0
    i=2  ch='('  → stack: [2, -1],  result=0,  sign=1
    i=3  ch='3'  → num=3
    i=4  ch='+'  → result += 3*1 = 3,  sign=1,  num=0
    i=5  ch='4'  → num=4
    i=6  ch=')'  → result += 4*1 = 7
                   st_sign  = -1  (popped)
                   last_res =  2  (popped)
                   result = 7 * (-1) + 2 = -5

    Output: -5 ✅

### Pseudocode

    calculate(s):
        num=0, result=0, sign=1
        stack=[]

        for ch in s:
            if ch == ' '  → skip
            if ch is digit → num = num*10 + digit
            if ch == '+'  → result += num*sign;  sign=+1;  num=0
            if ch == '-'  → result += num*sign;  sign=-1;  num=0
            if ch == '('  → stack.push(result, sign);  result=0;  sign=1
            if ch == ')'  → result += num*sign;  num=0
                             st_sign  = stack.pop()
                             last_res = stack.pop()
                             result = result * st_sign + last_res

        result += num * sign
        return result

### Full C++ Solution

```cpp
class Solution {
public:
    int calculate(string s) {
        int n = s.length();
        stack<long long> st;

        long long num = 0, result = 0;
        int sign = 1;

        for (int i = 0; i < n; i++) {
            if (s[i] == ' ') continue;

            if (isdigit(s[i])) {
                num = num * 10 + (s[i] - '0');      // build multi-digit number
            }
            else if (s[i] == '+') {
                result += num * sign;               // flush num
                num = 0; sign = 1;
            }
            else if (s[i] == '-') {
                result += num * sign;               // flush num
                num = 0; sign = -1;
            }
            else if (s[i] == '(') {
                st.push(result);                    // save current state
                st.push(sign);
                result = 0; sign = 1;               // fresh start inside ()
            }
            else if (s[i] == ')') {
                result += num * sign;               // flush num
                num = 0;

                long long st_sign  = st.top(); st.pop();  // restore state
                long long last_res = st.top(); st.pop();

                result = result * st_sign + last_res;     // merge
            }
        }

        result += num * sign;   // flush last number
        return (int)result;
    }
};
```

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | `sign` is `+1` or `-1` — multiplying by it elegantly handles `+` and `-` |
| 2 | Stack stores **exactly 2 values** per `(` — saved `result` and saved `sign` |
| 3 | `result = result * st_sign + last_res` is the **core merge formula** |
| 4 | Multi-digit numbers are built with `num = num * 10 + digit` |
| 5 | After the loop, the **last number** must be manually flushed |

---

## ⚠️ Common Mistakes

- ❌ **Forgetting to flush `num` at end of loop** → last number never added
- ❌ **Forgetting to flush before `(`** → actually no flush needed here, `num` should be 0 since a `+`/`-` always precedes `(`
- ❌ **Using `int` instead of `long long`** → overflow on large inputs
- ❌ **Popping in wrong order** → sign is pushed after result, so sign is popped **first**

    Expression: "a + b - (c + d)"
                              ↑
                At '(' → stack = [result_so_far, sign_before_bracket]
                At ')' → pop sign, pop result, merge inner result

    Stack always holds pairs: [result, sign, result, sign, ...]
    One pair per unclosed parenthesis level.
