# 🌡️ Daily Temperatures

> **Platform:** LeetCode | **Topic:** Stack | **Technique:** Monotonic Stack

**Question Link:** [https://leetcode.com/problems/daily-temperatures/](https://leetcode.com/problems/daily-temperatures/)

---

## 📌 Problem Summary

Given an array `temperatures`, return an array `ans` where `ans[i]` is the number of days you have to wait after day `i` to get a **warmer temperature**. If no warmer day exists, `ans[i] = 0`.

---

## 💡 Core Intuition

Use a **monotonic decreasing stack** that stores **indices** of temperatures. When we find a temperature greater than the one at the top of the stack, we've found the **next warmer day** for it. The answer is simply `current index - stored index`.

> 🌤️ **Analogy:** Imagine people waiting in a queue for a sunny day. As soon as a warmer day arrives, everyone in the queue who was colder gets their answer — "you waited this many days."

---

## 🤔 Why Store Indices Instead of Temperatures?

We need to compute the **number of days** between two temperatures, not just whether a warmer day exists. Storing the index lets us calculate `ans[idx] = i - idx` directly when we pop.

---

## 🪜 Algorithm Steps

1. 🏗️ Initialize `ans` array of size `n` with all `0s`
2. 📥 Iterate through each day `i`:
   - 🔁 While stack is **not empty** AND `temperatures[top] < temperatures[i]`:
     - 🗑️ Pop index `idx` from stack
     - ✅ Set `ans[idx] = i - idx`
   - 📥 Push current index `i` onto stack
3. 📤 Any index **left in stack** gets `ans = 0` (no warmer day found)

### Pseudocode

    dailyTemperatures(temps):
        ans = [0] * n
        stack = []   // stores indices

        for i from 0 to n-1:
            while stack not empty AND temps[stack.top] < temps[i]:
                idx = stack.pop()
                ans[idx] = i - idx       // days waited
            stack.push(i)

        return ans

### Full C++ Solution

```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = temperatures.size();
        vector<int> ans(n, 0);
        stack<int> st;   // stores indices

        for (int i = 0; i < n; i++) {
            // found a warmer day for indices in stack
            while (!st.empty() && temperatures[st.top()] < temperatures[i]) {
                int idx = st.top();
                st.pop();
                ans[idx] = i - idx;     // days waited
            }
            st.push(i);
        }
        return ans;
    }
};
```

## 📊 Complexity Analysis

| Metric | Complexity | Reason |
|--------|-----------|--------|
| ⏱️ **Time** | O(N) | Each index is pushed and popped at most once |
| 🧠 **Space** | O(N) | Stack holds at most N indices |

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | Stack stores **indices**, not temperatures — needed to compute distance |
| 2 | Stack is **monotonically decreasing** in temperature values |
| 3 | Unpopped indices at the end automatically get `ans = 0` (pre-filled) |
| 4 | The condition is **strict `<`** — equal temperatures don't count as warmer |

---

## ⚠️ Common Mistakes

- ❌ **Storing temperatures instead of indices** → can't compute `i - idx`
- ❌ **Using `<=` instead of `<`** → equal temp days would get a wrong answer
- ❌ **Not pre-filling ans with 0** → leftover stack indices need a default value

## 🆚 Daily Temperatures vs Stock Span

| Feature | Daily Temperatures | Stock Span |
|---------|-------------------|------------|
| Stack stores | Indices | {price, span} pairs |
| Goal | Days until next greater | Count of prev smaller/equal |
| Direction | Forward (next greater) | Backward (prev smaller) |
| Condition | strict `<` | `<=` |
