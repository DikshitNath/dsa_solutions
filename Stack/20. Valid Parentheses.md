# ✅ Valid Parentheses

> **Platform:** LeetCode | **Topic:** Stack | **Technique:** Push Expected Closing Bracket

**Question Link:** [https://leetcode.com/problems/valid-parentheses/](https://leetcode.com/problems/valid-parentheses/)

---

## 📌 Problem Summary

Given a string `s` containing only `(`, `)`, `{`, `}`, `[`, `]`, determine if the input string is **valid**. A string is valid if every opening bracket is closed by the **same type** in the **correct order**.

    "([]{})" → true
    "([)]"   → false
    "{[]}"   → true

---

## 💡 Core Intuition

When you see an **opening** bracket, push its **expected closing** bracket onto the stack. When you see a **closing** bracket, check if it matches the stack's top. If it does — pop and continue. If it doesn't — invalid.

> 🔑 **Trick:** Push the *closing* bracket instead of the opening one — eliminates the need for a separate matching lookup when checking.

---

## 🤔 Why Push the Closing Bracket?

Naive approach: push opening bracket, then on closing bracket look up what it matches.

This approach: push the **expected closing** bracket directly → when a closing bracket arrives, just compare with `st.top()` directly — no lookup needed.

    '(' → push ')'   → when ')' arrives, st.top() == ')' ✅ clean match
    '[' → push ']'
    '{' → push '}'

---

## 🪜 Algorithm Steps

1. 🔁 For each character `ch`:
   - `(` → push `)` onto stack
   - `[` → push `]` onto stack
   - `{` → push `}` onto stack
   - Closing bracket:
     - Stack empty → no matching opener → return `false`
     - `st.top() != ch` → wrong type → return `false`
     - `st.top() == ch` → valid match → pop
2. 📤 Return `st.empty()` — all openers must be matched

## 🧩 Code Walkthrough

### Dry Run — Valid

    s = "{[()]}"

    ch='{'  → push '}'   stack: [}]
    ch='['  → push ']'   stack: [}, ]]
    ch='('  → push ')'   stack: [}, ], )]
    ch=')'  → top=')', match ✅ pop   stack: [}, ]]
    ch=']'  → top=']', match ✅ pop   stack: [}]
    ch='}'  → top='}', match ✅ pop   stack: []

    st.empty() = true → return true ✅

### Dry Run — Invalid

    s = "([)]"

    ch='('  → push ')'   stack: [)]
    ch='['  → push ']'   stack: [), ]]
    ch=')'  → top=']' ≠ ')' → return false ✅

### Dry Run — Unmatched Opener

    s = "((("

    ch='(' → push ')' × 3   stack: [), ), )]

    st.empty() = false → return false ✅

### Pseudocode

    isValid(s):
        stack = []

        for ch in s:
            if ch == '(' → stack.push(')')
            if ch == '[' → stack.push(']')
            if ch == '{' → stack.push('}')
            else:                              // closing bracket
                if stack empty OR stack.top != ch → return false
                stack.pop()

        return stack.empty()

### Full C++ Solution

```cpp
class Solution {
public:
    bool isValid(string s) {
        stack<char> st;

        for (char ch : s) {
            if      (ch == '(') st.push(')');   // push expected closing
            else if (ch == '[') st.push(']');
            else if (ch == '{') st.push('}');
            else if (st.empty() || st.top() != ch)
                return false;                   // no match → invalid
            else
                st.pop();                       // matched → pop
        }
        return st.empty();                      // all openers matched?
    }
};
```

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | Push **closing** bracket on opening → direct comparison, no lookup table |
| 2 | Check `st.empty()` **before** `st.top()` — prevents undefined behavior |
| 3 | Final `return st.empty()` catches **unmatched openers** (e.g. `"((("`) |
| 4 | Closing bracket with empty stack = unmatched closer (e.g. `")"`) |

---

## ⚠️ Common Mistakes

- ❌ **Not checking `st.empty()` before `st.top()`** → crash on closing bracket with empty stack
- ❌ **Returning `true` without checking `st.empty()`** → unmatched openers slip through
- ❌ **Pushing opening brackets instead** → requires a separate match map on close

---

## 🔁 What Each Return Handles

    return false (st.empty())     → unmatched closing bracket: ")"
    return false (st.top() != ch) → mismatched type: "([)]"
    return false (!st.empty())    → unmatched opening bracket: "(("
    return true                   → perfectly balanced: "{[()]}"
