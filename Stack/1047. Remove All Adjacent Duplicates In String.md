# 🗑️ Remove All Adjacent Duplicates in String

> **Platform:** LeetCode | **Topic:** Stack | **Technique:** Stack as Buffer

**Question Link:** [https://leetcode.com/problems/remove-all-adjacent-duplicates-in-string/](https://leetcode.com/problems/remove-all-adjacent-duplicates-in-string/)

---

## 📌 Problem Summary

Given a string `s`, repeatedly remove **adjacent duplicate** characters until no more adjacent duplicates exist. Return the final string.

---

## 💡 Core Intuition

Use a **stack as a buffer**. For each character:
- If it **matches** the top of the stack → they're adjacent duplicates → **pop** (cancel both out)
- If it **doesn't match** → push it onto the stack

At the end, whatever remains in the stack is the result.

> 🧨 **Analogy:** Think of it like bubbles popping. When two identical bubbles touch, both vanish. Keep going until nothing adjacent is the same.

---

## 🤔 Why a Stack?

A stack naturally tracks the **last seen unmatched character**. When a new character arrives, we only need to check the **most recent** one — which is exactly what `st.top()` gives us in O(1).

---

## 🪜 Algorithm Steps

1. 🔁 Iterate through each character `ch` in the string
2. 🔍 Check the top of the stack:
   - `st.top() == ch` → 🗑️ **pop** (adjacent duplicate — cancel both)
   - Otherwise → 📥 **push** `ch`
3. 🏗️ Build result string from remaining stack characters
4. 🔄 **Reverse** the result (stack gives characters in reverse order)

---

## 🧩 Code Walkthrough

### Dry Run Example

    Input: s = "abbaca"

| Step | ch | Stack  | Action          |
|------|----|--------|-----------------|
| 1    | a  | [a]    | push a          |
| 2    | b  | [a,b]  | push b          |
| 3    | b  | [a]    | top==b → pop    |
| 4    | a  | []     | top==a → pop    |
| 5    | c  | [c]    | push c          |
| 6    | a  | [c,a]  | push a          |

    Stack left: [c, a] → reversed → "ca"
    Output: "ca" ✅

### Pseudocode

    removeDuplicates(s):
        stack = []

        for ch in s:
            if stack not empty AND stack.top == ch:
                stack.pop()        // cancel adjacent duplicates
            else:
                stack.push(ch)     // keep character

        ans = ""
        while stack not empty:
            ans += stack.top()
            stack.pop()

        reverse(ans)
        return ans

### Full C++ Solution

```cpp
class Solution {
public:
    string removeDuplicates(string s) {
        stack<char> st;

        for (char ch : s) {
            if (!st.empty() && st.top() == ch) {
                st.pop();               // adjacent duplicate — cancel both
            } else {
                st.push(ch);            // no match — keep it
            }
        }

        string ans = "";
        while (!st.empty()) {
            ans += st.top();            // build string from stack
            st.pop();
        }
        reverse(ans.begin(), ans.end()); // reverse since stack is LIFO
        return ans;
    }
};
```

## 📊 Complexity Analysis

| Metric | Complexity | Reason |
|--------|-----------|--------|
| ⏱️ **Time** | O(N) | Single pass through string + one reverse |
| 🧠 **Space** | O(N) | Stack holds at most N characters |

## ✅ Key Takeaways

| # | Insight |
|---|---------|
| 1 | Stack acts as a **smart buffer** — always exposes the last unmatched character |
| 2 | A pop + skip = **both characters cancelled** — no explicit pair tracking needed |
| 3 | Final reverse is needed because stack is **LIFO** (last in, first out) |
| 4 | This handles **chain reactions** naturally — e.g. `"abba"` → `""` in one pass |

---

## ⚠️ Common Mistakes

- ❌ **Forgetting to reverse** the final answer → string comes out backwards
- ❌ **Not checking `!st.empty()`** before `st.top()` → undefined behavior / crash
- ❌ **Using a simple loop approach** without stack → can't handle chain reactions in one pass

## 💥 Chain Reaction Example

    Input: "azxxzy"

    a → [a]
    z → [a,z]
    x → [a,z,x]
    x → [a,z]      // xx cancelled
    z → [a]        // zz cancelled
    y → [a,y]

    Output: "ay" ✅  — chain reaction handled in a single pass!
